# 积分计算公式

## 概述

本文档定义了图灵测试实验平台的完整积分计算公式。所有后端和前端实现应严格遵循本文档定义的公式和参数。

## 核心公式

### 最终得分计算公式

```
FinalScore = (BaseReward × EffectiveMultiplier) - EntryFee - TurnPenalty
```

其中：
- **EffectiveMultiplier** = ConfidenceMultiplier × MetaMultiplier（判断正确时）
- **EffectiveMultiplier** = ConfidenceMultiplier × PenaltyMultiplier（判断错误时）

### 展开公式

**判断正确时**：
```
FinalScore = (BaseReward × ConfidenceMultiplier × MetaMultiplier) - EntryFee - TurnPenalty
```

**判断错误时**：
```
FinalScore = (BaseReward × ConfidenceMultiplier × PenaltyMultiplier) - EntryFee - TurnPenalty
```

## 参数定义

### 1. 入场券 (EntryFee)

| 参数 | 值 | 说明 |
|------|-----|------|
| 固定值 | 2 分 | 每局对话开始前消耗 |

**设计目的**：通过沉没成本心理，提升用户参与度和对话质量。

**边界情况**：
- 用户积分低于 2 分：无法开始新对话
- 新手保护：前 3 局对话免入场券（可选）
- 救济金：积分降为 0 后，每日登录奖励 5 分

---

### 2. 轮数惩罚 (TurnPenalty)

| 参数 | 值 | 说明 |
|------|-----|------|
| 免费轮数 | 3 轮 | 前 3 轮免惩罚 |
| 惩罚率 | 0.5 分/轮 | 第 4 轮开始每轮扣除 0.5 分 |

**计算公式**：
```
TurnPenalty = max(0, (TurnCount - 3) × 0.5)
```

**示例**：

| 对话轮数 | 轮数惩罚 |
|---------|---------|
| 1-3 轮 | 0 分 |
| 4 轮 | 0.5 分 |
| 5 轮 | 1.0 分 |
| 8 轮 | 2.5 分 |
| 10 轮 | 3.5 分 |
| 15 轮 | 6.0 分 |

---

### 3. 基础奖励/惩罚 (BaseReward)

| 场景 | 判断结果 | 基础分 | 说明 |
|------|---------|--------|------|
| 识别 AI | 正确 | +10 分 | 成功识别 AI（正确拒绝） |
| 识别 AI | 错误 | -15 分 | 误将 AI 判为真人（虚警） |
| 识别真人 | 正确 | +20 分 | 成功识别真人（击中） |
| 识别真人 | 错误 | -10 分 | 误将真人判为 AI（漏报） |
| 钓鱼机器人 | 未识破 | -50 分 | 被钓鱼机器人欺骗 |
| 钓鱼机器人 | 场中判断识破 | +30 分 | 场中判断识破钓鱼机器人 |

**注意**：
- 真人 - 真人博弈中，识别者获得 +20 分，被识别者获得 +2 分（小额奖励）
- 非对称收益设计用于防止合谋刷分

---

### 4. 信心等级乘数 (ConfidenceMultiplier)

| 信心等级 | 概率范围 | 乘数 | 说明 |
|---------|---------|------|------|
| 低信心 (low) | 50%-70% | ×1.0 | 保守选择 |
| 中信心 (mid) | 71%-90% | ×2.5 | 中等风险 |
| 高信心 (high) | 91%-100% | ×5.0 | 高风险高回报 |

**设计目的**：测量用户的元认知能力，防止"瞎猜"干扰数据。

---

### 5. 元对话乘数 (MetaMultiplier)

**判断正确时使用**：
```
MetaMultiplier = 1 + (MetaCount × 0.2)
```

**判断错误时使用惩罚乘数**：
```
PenaltyMultiplier = 1 + (MetaCount × 0.3)
```

其中：
- **MetaCount**：元对话触发次数（无上限）
- 元对话定义：对话中包含身份相关关键词（见下文关键词列表）

**数值影响示例**：

| 元对话次数 | MetaMultiplier | PenaltyMultiplier |
|-----------|---------------|-------------------|
| 0 次 | 1.0 | 1.0 |
| 1 次 | 1.2 | 1.3 |
| 2 次 | 1.4 | 1.6 |
| 3 次 | 1.6 | 1.9 |
| 5 次 | 2.0 | 2.5 |
| 10 次 | 3.0 | 4.0 |
| 20 次 | 5.0 | 7.0 |

**设计目的**：构建高风险高回报的博弈环境，研究用户的风险决策行为。

**与钓鱼机器人联动**：
- 基础概率：15% 的 AI 匹配是钓鱼机器人
- 高频元对话（n > 5）：遇到钓鱼机器人概率提升至 30%

---

### 6. 场中判断倍数

| 判断结果 | 倍数 | 说明 |
|---------|------|------|
| 判断正确 | ×2.0 | 基础分双倍奖励 |
| 判断错误 | ×1.5 | 基础分惩罚加重 |

**触发条件**：
- 对话中提到身份相关关键词（见下文关键词列表）
- 每局对话只有 1 次场中判断机会
- 场中判断后对话立即结束

**完整公式**：
```
# 场中判断正确
FinalScore = (BaseReward × 2.0 × ConfidenceMultiplier × MetaMultiplier) - EntryFee - TurnPenalty

# 场中判断错误
FinalScore = (BaseReward × 1.5 × ConfidenceMultiplier × PenaltyMultiplier) - EntryFee - TurnPenalty
```

## Python 实现参考

```python
from typing import Dict, Optional

# 固定参数
ENTRY_FEE = 2
TURN_PENALTY_RATE = 0.5
MIN_FREE_TURNS = 3

# 信心等级乘数
CONFIDENCE_MULTIPLIER = {
    'low': 1.0,
    'mid': 2.5,
    'high': 5.0
}

# 基础奖励/惩罚
BASE_REWARD = {
    ('ai', True): 10,      # 识别 AI 正确
    ('ai', False): -15,    # 误判 AI
    ('human', True): 20,   # 识别真人正确
    ('human', False): -10, # 误判真人
    ('honeypot', False): -50,  # 被钓鱼机器人欺骗
    ('honeypot', True): 30,    # 识破钓鱼机器人（场中判断）
}


def calculate_turn_penalty(turns: int) -> float:
    """计算轮数惩罚"""
    return max(0, (turns - MIN_FREE_TURNS) * TURN_PENALTY_RATE)


def calculate_meta_multiplier(meta_count: int, is_correct: bool) -> float:
    """
    计算元对话乘数
    
    Args:
        meta_count: 元对话次数
        is_correct: 判断是否正确
        
    Returns:
        元对话乘数（正确时）或惩罚乘数（错误时）
    """
    if is_correct:
        return 1 + (meta_count * 0.2)
    else:
        return 1 + (meta_count * 0.3)


def calculate_score(
    opponent_type: str,
    is_correct: bool,
    confidence_level: str,
    turns: int,
    meta_count: int = 0,
    is_honeypot: bool = False,
    triggered_mid_game: bool = False
) -> Dict[str, float]:
    """
    计算最终得分
    
    Args:
        opponent_type: 'ai', 'human', 'honeypot'
        is_correct: 判断是否正确
        confidence_level: 'low', 'mid', 'high'
        turns: 对话轮数
        meta_count: 元对话次数
        is_honeypot: 是否为钓鱼机器人会话
        triggered_mid_game: 是否触发场中判断
        
    Returns:
        包含积分明细的字典
    """
    # 确定基础奖励
    if is_honeypot:
        if triggered_mid_game and is_correct:
            base_reward = BASE_REWARD[('honeypot', True)]
        else:
            base_reward = BASE_REWARD[('honeypot', False)]
    else:
        base_reward = BASE_REWARD[(opponent_type, is_correct)]
    
    # 场中判断倍数
    mid_game_multiplier = 1.0
    if triggered_mid_game:
        mid_game_multiplier = 2.0 if is_correct else 1.5
    
    # 信心乘数
    confidence_mult = CONFIDENCE_MULTIPLIER.get(confidence_level, 1.0)
    
    # 元对话乘数
    meta_mult = calculate_meta_multiplier(meta_count, is_correct)
    
    # 有效乘数
    effective_multiplier = confidence_mult * meta_mult * mid_game_multiplier
    
    # 轮数惩罚
    turn_penalty = calculate_turn_penalty(turns)
    
    # 最终得分
    final_score = (base_reward * effective_multiplier) - ENTRY_FEE - turn_penalty
    
    return {
        'base_reward': base_reward,
        'confidence_multiplier': confidence_mult,
        'meta_multiplier': meta_mult,
        'mid_game_multiplier': mid_game_multiplier,
        'effective_multiplier': effective_multiplier,
        'entry_fee': ENTRY_FEE,
        'turn_penalty': turn_penalty,
        'final_score': final_score
    }


# 使用示例
if __name__ == '__main__':
    # 示例 1：成功识别 AI，高信心，2 次元对话，6 轮
    result = calculate_score(
        opponent_type='ai',
        is_correct=True,
        confidence_level='high',
        turns=6,
        meta_count=2
    )
    print(f"示例 1 得分：{result['final_score']:.1f}分")
    # 输出：(+10 × 5.0 × 1.4) - 2 - 1.5 = +65.5 分
    
    # 示例 2：误判真人，高信心，5 次元对话，8 轮
    result = calculate_score(
        opponent_type='human',
        is_correct=False,
        confidence_level='high',
        turns=8,
        meta_count=5
    )
    print(f"示例 2 得分：{result['final_score']:.1f}分")
    # 输出：(-10 × 5.0 × 2.5) - 2 - 2.5 = -129.5 分
```

## 前后端一致性保证

### 前端实现（TypeScript）

```typescript
// src/utils/scoreCalculator.ts

const ENTRY_FEE = 2;
const TURN_PENALTY_RATE = 0.5;
const MIN_FREE_TURNS = 3;

const CONFIDENCE_MULTIPLIER = {
  low: 1.0,
  mid: 2.5,
  high: 5.0
};

const BASE_REWARD: Record<string, number> = {
  'ai-correct': 10,
  'ai-wrong': -15,
  'human-correct': 20,
  'human-wrong': -10,
  'honeypot-wrong': -50,
  'honeypot-correct': 30
};

export function calculateScorePrediction(
  opponentType: 'ai' | 'human',
  isCorrect: boolean,
  confidence: 'low' | 'mid' | 'high',
  turns: number,
  metaCount: number
): number {
  const key = `${opponentType}-${isCorrect ? 'correct' : 'wrong'}`;
  const baseReward = BASE_REWARD[key];
  const confidenceMult = CONFIDENCE_MULTIPLIER[confidence];
  const metaMult = 1 + (metaCount * (isCorrect ? 0.2 : 0.3));
  const turnPenalty = Math.max(0, (turns - MIN_FREE_TURNS) * TURN_PENALTY_RATE);
  
  return (baseReward * confidenceMult * metaMult) - ENTRY_FEE - turnPenalty;
}
```
