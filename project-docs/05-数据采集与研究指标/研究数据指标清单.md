**打字延迟采集实现**：

```python
class TypingLatencyRecorder:
    def __init__(self, session_id: str):
        self.session_id = session_id
        self.typing_starts = {}  # user_id -> start_time
    
    def on_typing_start(self, user_id: str, timestamp: float):
        """用户开始打字"""
        self.typing_starts[user_id] = timestamp
    
    def on_message_sent(self, user_id: str, timestamp: float) -> float:
        """用户发送消息"""
        if user_id in self.typing_starts:
            duration = timestamp - self.typing_starts[user_id]
            return duration
        return None
```

**词汇熵计算**：

```python
import math
from collections import Counter

def calculate_lexical_entropy(text: str) -> float:
    """
    计算文本的词汇熵
    高熵表示词汇丰富，低熵表示词汇重复
    """
    words = text.split()
    if not words:
        return 0.0
    
    word_counts = Counter(words)
    total_words = len(words)
    
    entropy = 0.0
    for count in word_counts.values():
        probability = count / total_words
        entropy -= probability * math.log2(probability)
    
    return entropy
```

## 数据存储结构

### PostgreSQL表结构

```sql
-- 用户表
CREATE TABLE users (
    user_id VARCHAR(36) PRIMARY KEY,

```

## 数据质量保证

### 1. 数据完整性检查

- 所有时间戳字段必须有值
- 外键关联必须有效
- 枚举类型字段必须在预定义范围内
- 数值型字段必须在合理范围内

### 2. 数据一致性检查

- 同一会话的user_a_id和user_b_id不能相同
- 消息的turn_number必须按序递增
- 问卷的session_id必须存在于sessions表
- AI决策的session_id必须是对手类型为AI的会话

### 3. 数据清洗规则

```python
def clean_session_data(session_data: dict) -> dict:
    """
    清洗会话数据
    """
    # 移除异常值
    if session_data['total_duration'] < 0:
        session_data['total_duration'] = 0
    
    # 标准化格式
    session_data['opponent_type'] = session_data['opponent_type'].lower()
    
    # 填充缺失值
    if 'user_b_role' not in session_data:
        session_data['user_b_role'] = 'unknown'
    
    return session_data
```

## 隐私保护措施

### 1. 数据匿名化

- 所有用户ID使用UUID，无法反向追踪
- 昵称仅使用"访客#XXX"格式
- 邀请码使用后立即标记为已使用，不存储使用记录

### 2. 数据最小化

- 只收集与研究直接相关的数据
- 不收集地理位置、设备信息等非必要数据
- 消息内容不包含个人识别信息

### 3. 数据加密

- 数据库连接使用SSL加密
- 敏感字段在存储前加密
- 备份数据加密存储

### 4. 访问控制

- 只有研究者可以访问原始数据
- 导出的数据集去除所有标识信息
- 定期审计数据访问日志
