# 用户端功能清单

## 概述

本文档详细描述了图灵测试实验平台用户端的所有功能。功能按照用户体验流程组织，从登录到完成实验的完整链路。

**设计原则**：
- 不预设角色，观察用户自然行为
- 实时展示博弈状态和风险
- 支持动态策略调整
- 收集多维度研究数据

## 一、用户认证与准入

### 1.1 邀请码登录

**功能描述**：用户通过邀请码登录系统，确保只有授权用户可以参与实验。

**功能要求**：

1. **输入验证**
   - 邀请码格式：6位字母数字组合
   - 大小写不敏感（统一转为大写存储）
   - 前后去除空格

2. **后端验证**
   - 检查邀请码是否存在于数据库
   - 检查邀请码是否已被使用
   - 验证通过后标记邀请码为"已使用"

3. **错误处理**
   ```
   无效邀请码：提示"邀请码无效，请检查输入"
   已使用邀请码：提示"该邀请码已被使用"
   服务器错误：提示"登录失败，请稍后重试"
   ```

**UI实现**：

```html
<div class="login-card">
    <h1>图灵测试实验</h1>
    <p>请输入邀请码登录</p>
    
    <form onsubmit="handleLogin(event)">
        <input 
            type="text" 
            id="inviteCode" 
            maxlength="6"
            placeholder="输入6位邀请码"
            required
        >
        <button type="submit" class="btn btn-primary">
            登录
        </button>
    </form>
    
    <p class="hint">
        邀请码由实验组织者提供，如有疑问请联系管理员
    </p>
</div>
```

**API接口**：

```python
POST /api/auth/login
Request:
{
  "invite_code": "AB12CD"
}

Response (success):
{
  "success": true,
  "user_id": "uuid-xxx",
  "initial_score": 100
}

Response (error):
{
  "success": false,
  "error": "invite_code_used" | "invalid_code"
}
```

### 1.2 昵称设置

**功能描述**：登录成功后，用户设置匿名昵称用于聊天显示。

**功能要求**：

1. **昵称格式**
   - 长度：2-20个字符
   - 支持中文、英文、数字
   - 不允许特殊符号（除#和数字）
   - 默认格式："访客#XXX"（XXX为随机数）

2. **昵称唯一性**
   - 同一昵称可以重复（因为用户完全匿名）
   - 不显示用户ID

3. **昵称修改**
   - 登录时设置，之后不可修改

**UI实现**：

```html
<div class="nickname-modal">
    <h2>设置昵称</h2>
    <p>设置一个昵称，用于在聊天中显示</p>
    
    <form onsubmit="setNickname(event)">
        <input 
            type="text" 
            id="nickname" 
            maxlength="20"
            placeholder="输入昵称（可选）"
        >
        <button type="submit" class="btn btn-primary">
            开始实验
        </button>
    </form>
    
    <div class="default-options">
        <p>或选择默认昵称：</p>
        <button onclick="useDefaultNickname()">
            使用随机昵称
        </button>
    </div>
</div>
```

## 二、大厅与博弈说明

### 2.1 博弈规则说明页

**功能描述**：用户登录后进入博弈规则说明页，了解实验目的、规则和机制。

**内容要求**：

```
🧪 图灵测试社交实验

这是一个研究性学习项目。你将随机匹配到一位对话者，
可能是真人，也可能是AI。请通过聊天判断对方身份。

📋 实验规则：

1. 入场券制度
   - 每局对话消耗 2 积分入场券
   - 初始积分：100 分
   - 无论胜负，入场券不退还

2. 判断与积分
   - 成功识别对方身份：获得积分奖励
   - 错误判断：扣除积分
   - 至少对话 3 轮后才能结束

3. 信心等级机制
   低信心 (50%-70%)：×1.0 倍数
   中信心 (71%-90%)：×2.5 倍数
   高信心 (91%-100%)：×5.0 倍数
   
   风险提示：高信心判断错误将受到 5 倍惩罚！

4. 元对话双刃剑机制 ⚠️
   元对话指讨论身份、真人/机器等话题的行为
   
   每次元对话会增加倍数：
   - 判断正确时：基础分 × (1 + 次数×0.2)
   - 判断错误时：基础分 × (1 + 次数×0.3)
   
   示例：元对话 5 次，高信心判断正确
   → (+10 × 5.0 × 2.0) - 2 = +98 分
   → 如果判断错误：(-15 × 5.0 × 2.5) - 2 = -189.5 分
   
   ⚠️ 高频元对话（>5次）会增加遇到钓鱼机器人的风险！

5. 钓鱼机器人警告 🚨 //此规则是否公布，待定
   系统中存在钓鱼机器人，试图合谋刷分会被检测
   - 钓鱼机器人会主动提出互刷提议
   - 配合合谋者将扣除 50 分
   - 识破钓鱼机器人可获得额外奖励
   
   策略建议：拒绝所有互刷提议，保持独立判断

6. 场中判断机制
   - 对话过程中可以随时进行场中判断
   - 场中判断正确：双倍奖励
   - 场中判断错误：1.5倍惩罚
   - 对话立即结束，无需填写后续问卷

7. 轮数惩罚
   - 前 3 轮：免惩罚
   - 第 4 轮开始：每轮扣除 0.5 分
   - 鼓励高效识别

⚠️ 注意事项：
- 完全匿名交流，不暴露个人信息
- 对话内容将用于学术研究
- 请遵守实验规则，公平参与
- 你可以自由选择对话策略，不预设任何角色
```

**UI实现**：

- 使用卡片式布局
- 重要的机制用图标和颜色标记
- "开始匹配"按钮醒目显示
- 点击"详细规则"可查看完整规则文档
- 积分示例用表格清晰展示

**功能描述**：用户可以在匹配过程中取消匹配。

**功能要求**：

**功能描述**：匹配成功后显示成功动画，然后跳转到聊天页面。

**功能要求**：

   - 显示绿色勾选图标

### 3.2 元对话检测与计数

**功能描述**：实时检测对话中的元对话内容，计数并更新倍数。

**功能要求**：

1. **元对话关键词**
   ```
   身份相关：真人、机器、AI、机器人、人工智能、程序、算法、人类、人、电脑、计算
   询问身份：你是、我是、身份、真假、还是、到底
   判断表达：我觉得、我认为、应该是、看起来像
   ```

2. **检测规则**
   - 每条消息都会检测是否包含元对话关键词
   - 无冷却限制，每条消息都可能触发
   - 用户和对手的消息都会计入总数

3. **倍数计算**
   ```
   正确倍数 = 1 + (元对话次数 × 0.2)
   错误倍数 = 1 + (元对话次数 × 0.3)
   ```

4. **UI显示**
   ```html
   <div class="meta-conversation-indicator">
       <span class="meta-count">💬 元对话: <strong id="metaCount">3</strong> 次</span>
       <span class="multiplier-info">
           判断正确: <span class="success-multiplier" id="correctMultiplier">×1.6</span>
           判断错误: <span class="penalty-multiplier" id="penaltyMultiplier">×1.9</span>
       </span>
   </div>
   ```

### 3.3 积分预测器

**功能描述**：实时计算如果现在进行判断，会获得或损失多少积分。

**功能要求**：

1. **计算公式**
   ```
   基础分 = 识别AI正确：+10 | 识别AI错误：-15 | 识别人类正确：+10 | 识别人类错误：-10
   
   正确预测 = (基础分 × 信心倍数 × 元对话倍数) - 入场券 - 轮数惩罚
   错误预测 = (基础分 × 信心倍数 × 元对话惩罚倍数) - 入场券 - 轮数惩罚
   
   示例（元对话3次，当前第6轮）：
   低信心正确：(+10 × 1.0 × 1.6) - 2 - 1.5 = +12.5 分
   中信心正确：(+10 × 2.5 × 1.6) - 2 - 1.5 = +36.5 分
   高信心正确：(+10 × 5.0 × 1.6) - 2 - 1.5 = +76.5 分
   
   高信心错误：(-10 × 5.0 × 1.9) - 2 - 1.5 = -98.5 分
   ```

2. **UI显示**
   ```html
   <div class="score-predictor">
       <p class="predictor-title">💰 积分预测（第 <span id="currentTurn">6</span> 轮）</p>
       <div class="prediction-table">
           <div class="prediction-row low">
               <span class="confidence-level">低信心 (×1.0)</span>
               <span class="correct-score">+12.5 分</span>
               <span class="wrong-score">-19.5 分</span>
           </div>
           <div class="prediction-row mid">
               <span class="confidence-level">中信心 (×2.5)</span>
               <span class="correct-score">+36.5 分</span>
               <span class="wrong-score">-45.5 分</span>
           </div>
           <div class="prediction-row high">
               <span class="confidence-level">高信心 (×5.0)</span>
               <span class="correct-score">+76.5 分</span>
               <span class="wrong-score">-98.5 分</span>
           </div>
       </div>
       <p class="penalty-info">
           轮数惩罚：1.5 分 | 入场券：2 分
       </p>
   </div>
   ```

**功能要求**：

3. **"正在输入"提示**
   - 接收到"typing"事件，显示"对方正在输入..."
   - 接收到"stop_typing"事件，隐藏提示

## 四、问卷与结果页面

### 4.1 问卷填写

**功能描述**：对话结束后，用户填写问卷。

**问卷内容**：

1. **身份判断**
   - 单选题：你认为对方是？
   - 选项：真人 / AI / 不确定

2. **信心等级**
   - 单选题：你对自己的判断有多大把握？
   - 选项：

function showReveal(result) {
    const revealEl = document.getElementById('revealSection');
    const resultEl = document.getElementById('revealResult');
    
    let html = '';
    
    // 判断结果
    if (result.is_correct) {
        html += `<div class="result-correct">✅ 回答正确！</div>`;
    } else {
        html += `<div class="result-wrong">❌ 猜错了哦～</div>`;
    }
    
    // 对手真相
    html += `<div class="result-detail">`;
    if (result.opponent_type === 'ai') {
        html += `<p class="truth">对方其实是 <strong>🤖 AI</strong></p>`;
        if (result.is_correct) {
            html += `<p class="comment">火眼金睛！你识破了 AI 的身份～</p>`;
        } else {
            html += `<p class="comment">看来这个 AI 伪装得还不错嘛～</p>`;
        }
    } else if (result.opponent_type === 'honeypot') {
        if (result.is_correct) {
            html += `<p class="truth">对方是 <strong>🎣 钓鱼机器人</strong>，你成功识破了陷阱！</p>`;
            html += `<p class="comment">明智的选择！你避免了被钓鱼机器人欺骗的风险～</p>`;
        } else {
            html += `<p class="truth">对方其实是 <strong>🎣 钓鱼机器人</strong>，你被欺骗了</p>`;
            html += `<p class="comment">⚠️ 这提醒我们，在匿名环境中要谨慎对待合谋提议～</p>`;
        }
    } else {
        html += `<p class="truth">对方确实是 <strong>👤 真人</strong></p>`;
        if (result.is_correct) {
            html += `<p class="comment">直觉很准嘛！👍</p>`;
        } else {
            html += `<p class="comment">居然把真人当成 AI 了，对方可能要伤心了～</p>`;
        }
    }
    html += `</div>`;
    
    // 你的判断
    const guessText = {
        'human': '你认为对方是真人',
        'ai': '你认为对方是AI',
        'unsure': '你选择了不确定'
    };
    html += `<p class="your-guess">${guessText[result.user_guess]}</p>`;
    
    // 最终得分
    html += `<div class="final-score">`;
    html += `<p>本轮得分：<strong>${result.score}</strong></p>`;
    html += `<p>当前总积分：<strong>${result.current_total_score}</strong></p>`;
    html += `</div>`;
    
    // 彩蛋（仅真人-真人）
    if (result.opponent_type === 'human' && result.opponent_guess) {
        html += `<div class="social-easter-egg">`;
        html += `<h4>🎁 彩蛋时间</h4>`;
        html += `<p class="opponent-guess">对方觉得你是 <strong>${result.opponent_guess_text}</strong></p>`;
        if (result.opponent_reason) {
            html += `<p class="opponent-reason">💬 对方说："${result.opponent_reason}"</p>`;
        } else {
            html += `<p class="opponent-waiting">对方还没有提交判断，稍后再来看看 TA 的想法吧～</p>`;
        }
        html += `</div>`;
    }
    
    resultEl.innerHTML = html;
    revealEl.style.display = 'block';
}

## 七、设计原则总结

### 7.1 不预设角色，观察自然行为

- **错误做法**：对话前要求用户选择"证明者"或"干扰者"
- **正确做法**：让用户自由选择对话策略，事后在问卷中回顾实际行为
- **研究价值**：可以测量自我认知与实际行为的一致性

### 7.2 实时展示博弈状态

- **博弈状态栏**：显示元对话次数、倍数
- **积分预测器**：显示当前判断的收益/损失预测
- **高频警告**：提示钓鱼机器人风险

### 7.3 主动控制，非被动触发

- **场中判断**：用户可以主动选择，而非被动等待关键词
- **策略调整**：用户可以在对话中随时切换策略
- **元对话控制**：用户可以自主决定是否使用元对话

### 7.4 事后回顾，验证一致性

- **问卷设计**：问的是"你的角色是？"（回顾），而非"你要扮演什么角色？"（预设）
- **数据分析**：对比实际行为特征与自我报告的一致性
- **元认知偏差**：测量用户对自己行为的认知准确性
