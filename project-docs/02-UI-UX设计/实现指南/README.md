## 核心功能亮点

### 1. 博弈状态栏
实时显示元对话次数、倍数、轮数惩罚，帮助用户做出明智决策。

### 2. 积分预测器
实时计算不同信心等级的收益/损失预测，透明展示积分计算过程。

### 3. 场中判断机制
用户可以主动触发场中判断，享受双倍奖励但也承担更高风险。

### 4. 元对话双刃剑
元对话可以提高奖励倍数，但也会增加惩罚倍数，形成风险-收益博弈。

### 5. 数据采集
完整记录用户行为数据，用于研究分析。
