## 一、技术栈选择

### 1.1 核心技术

#### 前端框架：Vue 3 (Composition API)

**选择理由**：
- 响应式系统完美契合实时更新的博弈状态
- Composition API 适合复杂的状态管理逻辑
- 良好的TypeScript支持
- 丰富的生态系统

**版本要求**：Vue 3.3+

```bash
npm install vue@latest
```

#### 构建工具：Vite

**选择理由**：
- 极速的冷启动和热更新
- 原生ES模块支持
- 优化的生产构建
- 良好的开发体验

```bash
npm create vite@latest turing-test-frontend -- --template vue-ts
```

#### 状态管理：Pinia

**选择理由**：
- Vue 3官方推荐的状态管理库
- 更简单的API，减少样板代码
- 良好的TypeScript支持
- 支持模块化Store

```bash
npm install pinia
```

#### UI框架：Element Plus（或自定义组件）

**选择理由**：
- 丰富的UI组件库
- 主题定制能力强
- 良好的可访问性
- 按需加载优化性能

```bash
npm install element-plus
```

**替代方案**：如果需要更高的定制性和轻量化，可以选择纯CSS + 自定义组件的方式。

#### 实时通信：原生 WebSocket API

**选择理由**：
- 浏览器原生支持，无需额外库
- 直接控制连接和消息处理
- 轻量高效
- 完全满足实验平台的实时通信需求

### 1.2 辅助库

#### HTTP客户端：Axios

```bash
npm install axios
```

用于RESTful API调用（登录、问卷提交等）。

#### 工具库：Lodash

```bash
npm install lodash-es
```

用于数据处理、防抖节流等工具函数。

#### 日期处理：Day.js

```bash
npm install dayjs
```

轻量级日期处理库（比moment.js小得多）。

## 三、架构设计原则

### 3.1 设计理念

#### 1. 组件化
- 每个功能模块封装为独立组件
- 组件职责单一，易于测试和维护
- 通过props和emits进行父子通信

#### 2. 响应式数据驱动
- 利用Vue 3的响应式系统
- 状态变化自动更新UI
- 减少手动DOM操作

#### 3. 状态管理
- 全局状态使用Pinia管理
- 组件内状态使用ref/reactive
- 明确区分全局状态和局部状态

#### 4. 代码复用
- 使用Composables提取公共逻辑
- 使用通用组件避免重复代码
- 工具函数独立管理

### 3.2 性能优化原则

#### 1. 懒加载
```typescript
// 路由懒加载
const Lobby = () => import('@/views/Lobby.vue')
const Chat = () => import('@/views/Chat.vue')
```

#### 2. 虚拟滚动
聊天消息列表使用虚拟滚动，避免大量DOM节点。

#### 3. 防抖节流
搜索、输入等高频操作使用防抖节流。

#### 4. 按需加载
Element Plus等UI库按需导入，减少打包体积。

### 3.3 可维护性原则

#### 1. 清晰的代码结构
- 按功能模块组织代码
- 使用有意义的命名
- 添加必要的注释

#### 2. TypeScript类型安全
- 为所有函数、变量添加类型注解
- 定义明确的接口类型
- 利用类型检查减少运行时错误

#### 3. 错误处理
- 统一的错误处理机制
- 友好的错误提示
- 错误日志记录

#### 4. 日志记录
- 关键操作记录日志
- 用户行为埋点
- 便于问题排查和数据分析

### 7.2 WebSocket通信

使用原生WebSocket API，结合Vue的生命周期：

```typescript
// composables/useWebSocket.ts
export function useWebSocket() {
  const ws = ref<WebSocket | null>(null)
  const isConnected = ref(false)
  const messageHandlers = ref<Map<string, Function>>(new Map())

  // 连接WebSocket
  function connect(url: string) {
    ws.value = new WebSocket(url)
    
    ws.value.onopen = () => {
      isConnected.value = true
    }
    
    ws.value.onmessage = (event) => {
      const data = JSON.parse(event.data)
      handleMessage(data)
    }
    
    ws.value.onclose = () => {
      isConnected.value = false
    }
  }

  // 注册消息处理器
  function onMessage(type: string, handler: Function) {
    messageHandlers.value.set(type, handler)
  }

  // 发送消息
  function send(data: any) {
    ws.value?.send(JSON.stringify(data))
  }

  return {
    isConnected,
    connect,
    onMessage,
    send
  }
}
```

### 7.3 元对话检测

```typescript
// composables/useMetaConversation.ts
const META_KEYWORDS = [
  '真人', '机器', 'AI', '机器人', '人工智能',
  '程序', '算法', '人类', '人', '电脑', '计算',
  '你是', '我是', '身份', '真假', '还是', '到底'
]

export function useMetaConversation() {
  const gameStore = useGameStore()

  // 检测是否为元对话
  function isMetaConversation(message: string): boolean {
    const lowerMessage = message.toLowerCase()
    return META_KEYWORDS.some(keyword => 
      lowerMessage.includes(keyword.toLowerCase())
    )
  }

  // 处理消息
  function handleMessage(message: string, sender: 'user' | 'opponent') {
    if (isMetaConversation(message)) {
      gameStore.incrementMetaCount()
    }
    return isMetaConversation(message)
  }

  return {
    isMetaConversation,
    handleMessage
  }
}
```

### 7.4 积分预测计算

```typescript
// composables/useScorePrediction.ts
export function useScorePrediction() {
  const gameStore = useGameStore()

  // 计算积分预测
  function calculatePrediction(turn: number, metaCount: number) {
    const ENTRY_FEE = 2
    const TURN_PENALTY_RATE = 0.5
    const MIN_FREE_TURNS = 3

    // 轮数惩罚
    const turnPenalty = Math.max(0, (turn - MIN_FREE_TURNS) * TURN_PENALTY_RATE)

    // 元对话乘数
    const metaMultiplier = 1 + (metaCount * 0.2)
    const penaltyMultiplier = 1 + (metaCount * 0.3)

    // 基础分
    const baseRewardIdentifyAI = 10   // 识别AI正确
    const baseRewardIdentifyHuman = 10 // 识别人类正确
    const basePenaltyMisidentifyAI = -15  // 误判AI为真人
    const basePenaltyMisidentifyHuman = -10 // 误判真人为AI

    // 计算不同信心等级的预测
    const lowConfidence = 1.0
    const midConfidence = 2.5
    const highConfidence = 5.0

    return {
      lowConfidence: {
        correct: (baseRewardIdentifyAI * lowConfidence * metaMultiplier) - ENTRY_FEE - turnPenalty,
        wrong: (basePenaltyMisidentifyAI * lowConfidence * penaltyMultiplier) - ENTRY_FEE - turnPenalty
      },
      midConfidence: {
        correct: (baseRewardIdentifyAI * midConfidence * metaMultiplier) - ENTRY_FEE - turnPenalty,
        wrong: (basePenaltyMisidentifyAI * midConfidence * penaltyMultiplier) - ENTRY_FEE - turnPenalty
      },
      highConfidence: {
        correct: (baseRewardIdentifyAI * highConfidence * metaMultiplier) - ENTRY_FEE - turnPenalty,
        wrong: (basePenaltyMisidentifyAI * highConfidence * penaltyMultiplier) - ENTRY_FEE - turnPenalty
      },
      metaMultiplier,
      penaltyMultiplier,
      turnPenalty,
      entryFee: ENTRY_FEE
    }
  }

  return {
    calculatePrediction
  }
}
```
