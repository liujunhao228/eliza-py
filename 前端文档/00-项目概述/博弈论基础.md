# 博弈论基础

## 理论框架概述

本实验平台基于多个博弈论和心理学理论构建，理解这些理论基础对于正确解读实验结果至关重要。

## 1. 信号检测理论 (Signal Detection Theory, SDT)

### 理论核心

信号检测理论最初用于雷达信号处理，后被引入心理学，用于研究观察者在不确定条件下如何区分信号（目标）和噪音（干扰）。

### 在本实验中的应用

将人机辨识问题建模为信号检测问题：

| 实际状态 \ 用户判断 | 判定为机器 | 判定为真人 |
|-------------------|-----------|-----------|
| **实际是机器** | 正确拒绝 (Correct Rejection) | 虚警 (False Alarm) |
| **实际是真人** | 漏报 (Miss) | 击中 (Hit) |

### 四种判断结果的博弈论含义

1. **正确拒绝**：成功识别机器
   - 用户收益：高
   - 研究价值：验证用户辨识能力

2. **击中**：成功识别真人
   - 用户收益：高（"共鸣奖金"）
   - 研究价值：体现人类社交直觉

3. **虚警**：误将机器判为真人
   - 用户收益：负值（-15分）
   - 研究价值：机器拟真度的直接体现

4. **漏报**：误将真人判为机器
   - 用户收益：负值（-10分）
   - 研究价值：真人拟态行为或人类刻板印象的体现

### 判定标准（β, Beta）

在信号检测理论中，判定标准（β）反映了观察者的策略倾向：

- **保守型标准**（高β）：倾向于保守判断，减少虚警，但可能增加漏报
- **冒险型标准**（低β）：倾向于冒险判断，减少漏报，但可能增加虚警
- **中性标准**（β=1）：在两种错误之间保持平衡

**本实验中的实现**：通过信心等级机制引导用户调整自己的判定标准。

## 2. 拟态博弈 (Mimicry Game)

### 理论核心

拟态博弈源于生物学中的拟态现象，指一个物种通过模仿另一个物种的特征来获取生存优势。在人类社会行为中，拟态表现为个人或组织通过模仿特定群体或身份来获得利益。

### 本实验中的拟态博弈

构建了一个三方拟态系统：

1. **A类：真正的机器**
   - 目标：模仿人类，通过图灵测试
   - 策略：基于Eliza规则的对话生成

2. **B类：真人（证明者）**
   - 目标：证明自己是真人
   - 策略：展现情感、逻辑灵活性、自然对话节奏

3. **C类：真人（干扰者）**
   - 目标：模拟机器，欺骗对方
   - 策略：减少词汇熵、控制打字节奏、使用固定句式、逻辑循环

### 拟态的演化稳定性 (Evolutionarily Stable Strategy, ESS)

在演化博弈论中，一个策略是演化稳定的，如果它在群体中占主导地位时，没有替代策略能侵入并取代它。

**研究问题**：
- 当大量用户选择"干扰者"策略时，系统是否会达到新的平衡？
- "证明者"和"干扰者"策略的收益比如何影响策略选择分布？

## 3. 囚徒困境 (Prisoner's Dilemma)

### 理论核心

囚徒困境是博弈论中最经典的非零和博弈模型，展示了个体理性选择如何导致集体非理性结果。

### 本实验中的应用场景

**合谋博弈**：两真人玩家在对话前通过外部渠道（如微信）约定互刷积分。

| 玩家A \ 玩家B | 配合互刷 | 拒绝/举报 |
|-------------|---------|----------|
| **配合互刷** | 双方各+2分（低效） | A扣50分，B+举报奖励 |
| **拒绝/举报** | A+举报奖励，B扣50分 | 双方正常博弈 |

### 非对称收益设计

通过非对称收益打破囚徒困境的合作均衡：

- 如果A判定B为真人且正确：A+20分，B+2分（或B不加）
- B必须后续也成功判定A，才能获得大额奖励

**效果**：合谋中的一方有强烈动机"背叛"，从而瓦解合谋基础。

## 4. 信号博弈 (Signaling Game)

### 理论核心

信号博弈研究信息不对称情境下的策略性沟通。发送方发送信号，接收方根据信号更新信念并采取行动。

### 本实验中的信号博弈

**发送方（对话者）**：
- 证明者：发送"我是真人"的信号（情感表达、灵活性等）
- 干扰者：发送"我是机器"的信号（重复、冷漠、固定模式）

**接收方（判断者）**：
- 观察信号
- 更新关于对手身份的信念
- 选择判断策略

### 信号的可信度

信号博弈的核心问题是信号的可信度：

1. **分离均衡 (Separating Equilibrium)**
   - 不同类型的发送方发送不同信号
   - 接收方能完全区分类型
   - 研究价值：识别出哪些信号能有效区分人与机器

2. **混同均衡 (Pooling Equilibrium)**
   - 不同类型的发送方发送相同信号
   - 接收方无法区分
   - 研究价值：哪些拟态行为能够成功混淆判断

## 5. 期望效用理论 (Expected Utility Theory)

### 理论核心

期望效用理论描述理性决策者在不确定性下如何选择行动，通过计算各选项的期望效用最大化期望收益。

### 本实验中的应用

**场中判断的期望效用计算**：

设用户在第n轮进行提前判断：

- 判断正确的概率：P(correct|n)
- 判断错误的概率：1 - P(correct|n)
- 判断正确收益：R_correct(n) （随轮数n增加而减少）
- 判断错误损失：L_wrong(n) （随轮数n增加而增加）

期望效用：
```
EU(n) = P(correct|n) × R_correct(n) + (1 - P(correct|n)) × L_wrong(n)
```

**研究问题**：
- 用户如何根据对话轮数n调整自己的判断阈值？
- 用户的实际决策是否符合期望效用最大化？

## 6. 认知偏差理论

### 过度自信偏差 (Overconfidence Bias)

研究表明，人类普遍存在过度自信倾向，高估自己判断的准确性。

**本实验中的表现**：
- 用户选择"高信心"（91-100%）的频率可能过高
- 高信心判断的准确率可能低于预期

**测量方法**：
- 计算信心等级与实际准确率的校准曲线
- 识别过度置信的个体特征

### 确认偏差 (Confirmation Bias)

人们倾向于寻找和重视支持自己已有信念的信息。

**本实验中的表现**：
- 用户可能过早形成判断，然后寻找支持证据
- 忽略与自己初始判断相矛盾的信息

**研究问题**：
- 场中判断是否会放大确认偏差？
- 提前判断的准确率是否低于对话结束后的判断？

### 锚定效应 (Anchoring Effect）

人们在做判断时过分依赖获得的第一条信息（锚点）。

**本实验中的表现**：
- 对话前几句可能成为判断的"锚点"
- 后续信息难以改变初始印象

**研究价值**：
- 分析对话中判断转折点
- 识别哪些信息能够有效改变用户判断

## 7. 元认知理论 (Metacognition)

### 理论核心

元认知指对自己的认知过程的认识和调控，包括元认知知识、元认知监控和元认知调节。

### 本实验中的元认知测量

**信心等级机制**实际上测量了用户的元认知监控能力：

1. **元认知知识**：用户是否知道自己在哪些方面擅长辨识？
2. **元认知监控**：用户能否准确评估自己的判断确定性？
3. **元认知调节**：用户能否根据不确定性调整判断策略？

**研究指标**：
- 信心-准确率校准度
- 高信心判断的准确性
- 低信心判断的准确性
- 信心等级的动态变化

## 8. 暗黑森林理论 (Dark Forest Theory)

### 理论起源

来自刘慈欣的科幻小说《三体》，描述了宇宙文明在无法相互信任时的生存策略。

### 本实验中的"暗黑森林"心理

引入钓鱼机器人后，系统形成"暗黑森林"环境：

1. **文明不能相互暴露**
   - 用户无法确定对方是真人、正常AI，还是钓鱼机器人
   - 提出互刷提议可能来自真人，也可能是钓鱼机器人的陷阱

2. **沉默是最安全的**
   - 为避免被钓鱼机器人惩罚，用户倾向于拒绝所有合谋提议
   - 信任机制在不确定性下瓦解

3. **猜疑链形成**
   - "他可能是真人想合谋"
   - "他可能是钓鱼机器人想骗我"
   - "他可能是真人但怀疑我是钓鱼机器人"

**研究价值**：
- 观察"暗黑森林"心理的形成过程
- 研究匿名环境下信任机制的脆弱性
- 分析威慑策略对社会合作行为的影响

## 9. 合作演化理论 (Evolution of Cooperation)

### 理论核心

研究自私个体如何演化出合作行为。经典模型包括：

- **直接互惠**：Tit-for-Tat策略
- **间接互惠**：声誉系统
- **网络互惠**：社会结构
- **群体选择**：群体间竞争

### 本实验中的观察角度

1. **互惠行为的出现与消失**
   - 真人-真人博弈中是否会自然出现互惠合作？
   - 钓鱼机器人威慑下，互惠行为如何变化？

2. **声誉系统的影响**
   - 不设置公开排行榜（避免策略收敛）
   - 但用户内心是否会形成"声誉"认知？

3. **合作破裂的临界点**
   - 多少比例的钓鱼机器人会导致合作完全崩溃？
   - 合谋检测的阈值如何影响信任重建？

## 10. 博弈论概念总结表

| 概念 | 英文 | 在本实验中的应用 |
|------|------|------------------|
| 信号检测 | Signal Detection | 判断对方身份的四种结果 |
| 拟态博弈 | Mimicry Game | 人类模仿机器行为 |
| 囚徒困境 | Prisoner's Dilemma | 互刷合谋的博弈 |
| 信号博弈 | Signaling Game | 通过对话发送身份信号 |
| 期望效用 | Expected Utility | 场中判断的决策计算 |
| 过度自信 | Overconfidence | 信心等级与准确率的偏差 |
| 确认偏差 | Confirmation Bias | 过早形成判断倾向 |
| 锚定效应 | Anchoring Effect | 初始信息的持续影响 |
| 元认知 | Metacognition | 对判断确定性的自我监控 |
| 暗黑森林 | Dark Forest | 钓鱼机器人威慑下的不信任心理 |
| 演化稳定 | ESS | 证明者/干扰者策略的演化 |
| 直接互惠 | Direct Reciprocity | 真人间的合作行为 |

## 研究问题的博弈论视角

基于以上理论，本研究的核心问题可以重新表述：

1. **拟态的演化稳定性**：证明者和干扰者策略的收益比如何影响策略选择分布？是否存在演化稳定均衡？

2. **信号的可信度分离**：哪些信号能有效实现"分离均衡"（区分人与机器），哪些信号会导致"混同均衡"（无法区分）？

3. **元认知的校准度**：用户信心等级与实际判断准确率的偏离程度是多少？过度自信现象有多普遍？

4. **合作与信任的脆弱性**：钓鱼机器人的威慑效应有多强？暗黑森林心理形成的临界条件是什么？

5. **决策的期望效用**：用户的场中判断决策是否符合期望效用最大化？存在哪些系统性的认知偏差？

6. **博弈策略的收敛与分化**：在多轮实验中，用户策略是否会收敛到特定的模式？不同用户的策略选择是否呈现分化？
