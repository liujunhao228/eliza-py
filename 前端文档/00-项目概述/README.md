# 图灵测试社交实验平台 - 文档导航

## 项目简介

本项目是一个基于积分激励的人机辨识博弈实验平台，研究人类在利益驱动下的行为拟态现象。通过让用户与真人或AI进行对话，并记录用户的判断、信心等级和自我角色选择，来探索人类如何模拟机器行为，以及这种行为背后的心理机制。

**研究题目**：《基于积分激励的人机辨识博弈中人类行为拟态研究》
