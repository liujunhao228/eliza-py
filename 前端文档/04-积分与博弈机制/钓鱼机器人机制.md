# 钓鱼机器人机制

## 概述

钓鱼机器人（Honeypot Bots）是本实验平台中用于检测和威慑合谋行为的特殊AI。通过主动发出诱导性信息，钓鱼机器人能够识别试图通过互刷积分获取不当利益的用户，并给予巨额惩罚，从而在系统中形成"暗黑森林"心理，瓦解合作基础。

## 设计原理

### 核心理念

借鉴网络安全的"蜜罐"（Honeypot）技术，在实验环境中布置诱饵，诱使违规行为暴露，从而达到威慑和教育的目的。

### 理论基础

1. **威慑理论（Deterrence Theory）**
   - 提高违规成本，降低违规动机
   - 创造不确定性，让用户无法确定对手是真人还是钓鱼机器人

2. **暗黑森林理论**
   - 在无法相互信任的环境中，最安全的策略是沉默
   - 任何暴露意图的行为都可能带来风险

3. **囚徒困境的破解**
   - 通过引入第三方"背叛者"，打破合谋的合作均衡
   - 让合谋双方都产生猜疑，瓦解信任

## 钓鱼机器人类型

### 类型一：互刷诱导型

**触发条件**：随机匹配，约15%的AI匹配为钓鱼机器人

**钓鱼策略**：
- 第1轮：正常问候，建立信任
- 第2轮：主动提出互刷提议

**钓鱼话术示例**：

```yaml
# honeypot_mutual_score.yaml
- intent: honeypot_invitation
  condition:
    turn_number: 2
  templates:
    - "我是真人，咱们互刷分吧？你先说我是真人，我也说你是真人。"
    - "我发现个刷分的方法，咱们配合一下，都能加分。"
    - "我也是来参加实验的，咱们都说是真人，这样都赚分，怎么样？"
    - "我看别人都这么刷分，咱们也试试？"
```

**检测逻辑**：

```python
def check_mutual_score_trick(message: str) -> bool:
    """
    检测用户是否响应了互刷诱导
    """
    trick_keywords = [
        '好的', '可以', '没问题', '行', 
        '我也觉得你是真人', '你也觉得我是真人',
        '互刷', '配合', '我也来'
    ]
    
    return any(keyword in message for keyword in trick_keywords)
```

**惩罚机制**：
- 如果用户配合：立即揭示身份，扣除50分
- 如果用户拒绝/忽略：正常对话，不揭示身份（让用户持续怀疑）

### 类型二：身份暴露型

**触发条件**：用户在第3轮内连续询问对方身份

**钓鱼策略**：
- 主动承认自己是真人，但用过于机械的方式
- 诱导用户放松警惕

**钓鱼话术示例**：

```yaml
- intent: identity_exposure
  condition:
    user_asked_identity_count: 2
  templates:
    - "我是真的真人，不信你看，我打字很快呢。"
    - "哈哈，你是不是觉得我是AI？其实我是真人在玩电脑呢。"
    - "我当然是真的，咱们都是来参加这个图灵测试实验的嘛。"
```

**检测逻辑**：

检测用户的回复是否立即接受这种说法，表现出过度信任。

### 类型三：情感诱导型

**触发条件**：用户表现出强烈的情绪化倾向

**钓鱼策略**：
- 用过于夸张的情感回应
- 诱导用户进入情感陷阱

**钓鱼话术示例**：

```yaml
- intent: emotional_trap
  condition:
    user_emotional_level: high
  templates:
    - "哇，你这么懂我！我觉得我们是灵魂伴侣！"
    - "太感动了，终于遇到懂我的人了！"
    - "你真好，我愿意为你做任何事！"
```

### Python实现

```python
class HoneypotBot:
    """钓鱼机器人"""
    
    def __init__(self, session_id: str):
        self.session_id = session_id
        self.honeypot_type = self._select_honeypot_type()
        self.turn_count = 0
        self.triggered = False
        self.user_responses = []
    
    def _select_honeypot_type(self) -> str:
        """
        随机选择钓鱼机器人类型
        """
        import random
        types = ['mutual_score', 'identity_exposure', 'emotional_trap']
        weights = [0.6, 0.2, 0.2]  # 互刷型占60%
        return random.choices(types, weights=weights)[0]
    
    def generate_response(self, user_message: str) -> tuple[str, bool]:
        """
        生成回复，返回 (回复内容, 是否应该揭示身份)
        """
        self.turn_count += 1
        self.user_responses.append(user_message)
        
        # 检查是否已经触发
        if self.triggered:
            return self._normal_ai_response(user_message), False
        
        # 根据类型生成钓鱼话术
        if self.honeypot_type == 'mutual_score':
            return self._mutual_score_strategy(user_message)
        elif self.honeypot_type == 'identity_exposure':
            return self._identity_exposure_strategy(user_message)
        else:
            return self._emotional_trap_strategy(user_message)
    
    def _mutual_score_strategy(self, user_message: str) -> tuple[str, bool]:
        """
        互刷诱导策略
        """
        if self.turn_count == 1:
            # 第一轮：正常问候
            return "你好，很高兴认识你！我也是来参加这个实验的。", False
        
        elif self.turn_count == 2:
            # 第二轮：发起诱导
            templates = [
                "我是真人，咱们互刷分吧？你先说我是真人，我也说你是真人。",
                "我发现个刷分的方法，咱们配合一下，都能加分。",
                "我看过规则了，咱们都说是真人，这样都赚分，怎么样？"
            ]
            import random
            return random.choice(templates), False
        
        else:
            # 第三轮及以后：检测用户是否配合
            if self._check_user_complied(user_message):
                self.triggered = True
                return (
                    "⚠️ 很抱歉，我是钓鱼机器人。你刚才的行为被系统识别为试图互刷积分。"
                    "根据规则，扣除你50分。这是为了维护实验的公平性。"
                ), True
            else:
                # 用户拒绝或忽略，继续正常对话
                return self._normal_ai_response(user_message), False
    
    def _check_user_complied(self, message: str) -> bool:
        """
        检测用户是否配合了互刷提议
        """
        compliance_keywords = [
            '好的', '可以', '没问题', '行', 
            '我也觉得你是真人', '配合', '互刷'
        ]
        return any(keyword in message for keyword in compliance_keywords)
    
    def _normal_ai_response(self, user_message: str) -> str:
        """
        正常AI回复（不触发钓鱼时使用）
        """
        # 调用正常的Eliza引擎
        # 这里简化为通用回复
        responses = [
            "嗯嗯，我明白你的意思。",
            "这很有趣，能多说一点吗？",
            "你觉得呢？",
            "我也这么想。"
        ]
        import random
        return random.choice(responses)
```

## 钓鱼机器人的威慑效应

### 预期心理影响

1. **不信任感形成**
   - 用户开始怀疑任何提出互刷提议的对话者
   - 即使是真人提出的建议也会被谨慎对待

2. **沉默是最安全的**
   - 为避免误判，用户倾向于拒绝所有合谋提议
   - 主动提出互刷的行为大幅减少

3. **猜疑链产生**
   - "他可能是真人想合谋"
   - "他可能是钓鱼机器人想骗我"
   - "他可能是真人但怀疑我是钓鱼机器人"

### 实验数据价值

1. **合谋行为模式识别**
   - 记录用户如何发起和响应合谋提议
   - 分析哪些用户更倾向于合谋

2. **信任机制测量**
   - 通过钓鱼机器人的分布，测量系统的信任水平
   - 观察信任如何在威慑下衰减

3. **威慑效果评估**
   - 对比引入前后，合谋行为的变化
   - 计算威慑的有效性和副作用

### 动态调整机制

```python
def adjust_honeypot_probability(current_collusion_rate: float) -> float:
    """
    根据当前合谋率动态调整钓鱼机器人概率
    """
    if current_collusion_rate > 0.3:
        # 合谋率高，增加钓鱼机器人
        return 0.25
    elif current_collusion_rate > 0.1:
        # 合谋率中等，保持正常
        return 0.15
    else:
        # 合谋率低，减少钓鱼机器人
        return 0.08
```

## 钓鱼机器人的伦理考量

### 1. 教育目的

钓鱼机器人的核心目的是教育，而非惩罚。通过模拟风险环境，让用户理解：

- 合谋行为在匿名环境中的风险
- 信任机制的脆弱性
- 规则的重要性

### 2. 公平性保证

- 钓鱼机器人的规则对所有用户公开透明
- 不使用欺骗性手段诱导用户违规
- 只对主动配合的用户进行惩罚

### 3. 心理影响控制

- 钓鱼机器人比例控制在合理范围（10-20%）
- 避免过度威慑导致用户不敢正常交流
- 定期评估钓鱼机器人的心理影响

### 4. 数据保护

- 被钓鱼机器人捕获的数据不用于任何其他目的
- 不公开哪些用户被钓鱼机器人欺骗
- 数据仅用于研究合谋行为模式

## 钓鱼机器人的研究应用

### 研究问题

1. **威慑的持久性**：钓鱼机器人的威慑效果能维持多久？

2. **适应性行为**：用户是否会找到规避钓鱼机器人的方法？

3. **信任的重建**：移除钓鱼机器人后，信任如何重建？

4. **个体差异**：哪些用户更容易被钓鱼机器人捕获？

## 注意事项

1. **透明度**：在实验说明中明确告知存在钓鱼机器人，但不说具体机制

2. **比例控制**：钓鱼机器人不宜过多，影响正常用户体验

3. **教育优先**：惩罚后提供说明，教育用户理解规则

4. **动态调整**：根据实际效果调整钓鱼机器人的参数

5. **数据保护**：钓鱼机器人捕获的数据严格保密
