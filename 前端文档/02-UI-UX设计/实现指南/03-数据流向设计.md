# 数据流向设计

## 文档说明

本文档详细说明图灵测试实验平台前端的数据流向，包括前端与后端的交互流程、WebSocket通信流程、数据流转时序图、错误处理机制等。

---

## 一、整体数据流向

### 1.1 数据流架构

```
┌─────────────────────────────────────────────────────────────┐
│                        用户浏览器                           │
│  ┌──────────────┐    ┌──────────────┐    ┌──────────────┐ │
│  │   Vue组件     │ ↔  │  Pinia Store │ ↔  │ Composables  │ │
│  │   (UI层)      │    │  (状态层)     │    │  (逻辑层)     │ │
│  └──────────────┘    └──────────────┘    └──────────────┘ │
│         ↓                     ↓                     ↓        │
│  ┌──────────────────────────────────────────────────────┐   │
│  │                 数据访问层                          │   │
│  │  ┌──────────┐         ┌──────────┐                │   │
│  │  │  Axios   │         │WebSocket │                │   │
│  │  │ (HTTP)   │         │  (实时)   │                │   │
│  │  └──────────┘         └──────────┘                │   │
│  └──────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                              ↓ HTTP + WebSocket
┌─────────────────────────────────────────────────────────────┐
│                     后端服务器                              │
│  ┌──────────┐    ┌──────────┐    ┌──────────┐            │
│  │  RESTful  │    │WebSocket │    │  数据库  │            │
│  │   API     │    │  Server  │    │ (PostgreSQL)│          │
│  └──────────┘    └──────────┘    └──────────┘            │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 数据流类型

#### 1. HTTP请求流（RESTful API）
```
用户操作 → 组件事件 → API调用 → 后端处理 → 数据库 → 返回结果 → 更新状态 → UI更新
```

**适用场景**：
- 用户登录/注册
- 邀请码验证
- 昵称设置
- 问卷提交
- 个人数据查询
- 匹配请求/取消

#### 2. WebSocket实时流
```
用户操作 → 发送WebSocket消息 → 后端广播 → 所有客户端接收 → 更新状态 → UI更新
```

**适用场景**：
- 实时聊天消息
- 对手"正在输入"状态
- 场中判断触发
- 对话结束通知
- 元对话计数更新

### 2.2 数据流转代码示例

```typescript
// Login.vue
<script setup lang="ts">
import { ref } from 'vue'
import { useRouter } from 'vue-router'
import { useUserStore } from '@/stores/user'
import { login, setNickname } from '@/api/auth'
import { ElMessage } from 'element-plus'

const router = useRouter()
const userStore = useUserStore()

const inviteCode = ref('')
const nickname = ref('')
const showNicknameModal = ref(false)

// 登录流程
async function handleLogin() {
  try {
    // 1. 前端验证
    if (!inviteCode.value || inviteCode.value.length !== 6) {
      ElMessage.error('请输入6位邀请码')
      return
    }

    // 2. 调用API
    const response = await login({ inviteCode: inviteCode.value.toUpperCase() })
    
    // 3. 更新状态
    userStore.login({
      userId: response.user_id,
      nickname: '',
      inviteCode: inviteCode.value.toUpperCase()
    })
    
    // 4. 显示昵称设置弹窗
    showNicknameModal.value = true
    
  } catch (error) {
    // 错误已在axios拦截器中统一处理
    console.error('登录失败:', error)
  }
}

// 设置昵称流程
async function handleSetNickname() {
  try {
    // 1. 调用API
    await setNickname(nickname.value || `访客#${Math.floor(Math.random() * 1000)}`)
    
    // 2. 更新状态
    userStore.nickname = nickname.value || `访客#${Math.floor(Math.random() * 1000)}`
    
    // 3. 关闭弹窗
    showNicknameModal.value = false
    
    // 4. 跳转到大厅
    router.push('/lobby')
    
  } catch (error) {
    console.error('设置昵称失败:', error)
  }
}
</script>
```

### 3.2 匹配数据流代码示例

```typescript
// Lobby.vue
<script setup lang="ts">
import { ref, onUnmounted } from 'vue'
import { useRouter } from 'vue-router'
import { useSessionStore } from '@/stores/session'
import { useGameStore } from '@/stores/game'
import { useWebSocket } from '@/composables/useWebSocket'
import { startMatch, cancelMatch } from '@/api/match'
import { ElMessage } from 'element-plus'

const router = useRouter()
const sessionStore = useSessionStore()
const gameStore = useGameStore()

const isMatching = ref(false)
const matchRequestId = ref('')

// WebSocket连接
const { isConnected, connect, onMessage, send, disconnect } = useWebSocket()

// 开始匹配
async function handleStartMatch() {
  try {
    // 1. 调用API
    const response = await startMatch()
    matchRequestId.value = response.request_id
    
    // 2. 更新状态
    isMatching.value = true
    sessionStore.startMatching()
    
    // 3. 建立WebSocket连接
    const wsUrl = `${import.meta.env.VITE_WS_BASE_URL}/match/${matchRequestId.value}`
    connect(wsUrl)
    
    // 4. 注册消息处理器
    onMessage('matched', handleMatched)
    onMessage('error', handleMatchError)
    
  } catch (error) {
    console.error('开始匹配失败:', error)
    isMatching.value = false
  }
}

// 匹配成功
function handleMatched(data: any) {
  console.log('匹配成功:', data)
  
  // 1. 更新Session Store
  sessionStore.matchSuccess({
    sessionId: data.session_id,
    opponentType: data.opponent_type,
    opponentId: data.opponent_id,
    matchDuration: data.match_duration
  })
  
  // 2. 初始化Game Store
  gameStore.reset()
  
  // 3. 跳转到聊天页
  router.push('/chat')
}

// 匹配错误
function handleMatchError(data: any) {
  console.error('匹配错误:', data)
  ElMessage.error(data.message || '匹配失败')
  isMatching.value = false
}

// 取消匹配
async function handleCancelMatch() {
  try {
    // 1. 关闭WebSocket
    disconnect()
    
    // 2. 调用API
    await cancelMatch(matchRequestId.value)
    
    // 3. 重置状态
    isMatching.value = false
    matchRequestId.value = ''
    
  } catch (error) {
    console.error('取消匹配失败:', error)
  }
}

// 组件卸载时清理
onUnmounted(() => {
  if (isMatching.value) {
    disconnect()
  }
})
</script>
```

### 4.2 聊天数据流代码示例

```typescript
// Chat.vue
<script setup lang="ts">
import { ref, computed, watch, nextTick, onMounted, onUnmounted } from 'vue'
import { useRouter } from 'vue-router'
import { useGameStore } from '@/stores/game'
import { useSessionStore } from '@/stores/session'
import { useWebSocket } from '@/composables/useWebSocket'
import { useMetaConversation } from '@/composables/useMetaConversation'
import { endChat } from '@/api/chat'
import { ElMessage } from 'element-plus'

const router = useRouter()
const gameStore = useGameStore()
const sessionStore = useSessionStore()

const { connect, onMessage, send, disconnect } = useWebSocket()
const { isMetaConversation: checkMeta } = useMetaConversation()

const inputMessage = ref('')
const messageListRef = ref<HTMLElement | null>(null)
const showEndChatModal = ref(false)

// 发送消息
async function handleSendMessage() {
  const content = inputMessage.value.trim()
  
  // 1. 前端验证
  if (!content) {
    ElMessage.warning('请输入消息内容')
    return
  }
  
  if (content.length > 500) {
    ElMessage.warning('消息长度不能超过500字')
    return
  }
  
  // 2. 元对话检测
  const isMeta = checkMeta(content)
  
  // 3. 添加到本地消息列表
  const message: Message = {
    id: `msg_${Date.now()}`,
    sender: 'user',
    content,
    timestamp: new Date(),
    isMetaConversation: isMeta
  }
  
  gameStore.addMessage(message)
  
  // 4. 更新轮数和元对话计数
  gameStore.incrementTurn()
  if (isMeta) {
    gameStore.incrementMetaCount()
  }
  
  // 5. 发送到WebSocket
  send({
    type: 'chat',
    content,
    isMetaConversation: isMeta
  })
  
  // 6. 清空输入框
  inputMessage.value = ''
  
  // 7. 滚动到底部
  await scrollToBottom()
}

// 接收消息
function handleReceiveMessage(data: any) {
  console.log('收到消息:', data)
  
  // 1. 元对话检测
  const isMeta = checkMeta(data.content)
  
  // 2. 添加到消息列表
  const message: Message = {
    id: data.id,
    sender: 'opponent',
    content: data.content,
    timestamp: new Date(data.timestamp),
    isMetaConversation: isMeta
  }
  
  gameStore.addMessage(message)
  
  // 3. 更新元对话计数
  if (isMeta) {
    gameStore.incrementMetaCount()
  }
  
  // 4. 滚动到底部
  scrollToBottom()
}

// 滚动到底部
async function scrollToBottom() {
  await nextTick()
  if (messageListRef.value) {
    messageListRef.value.scrollTop = messageListRef.value.scrollHeight
  }
}

// 结束对话
async function handleEndChat() {
  // 检查最低轮数
  if (gameStore.turn < 3) {
    ElMessage.warning(`请至少对话3轮后再结束（当前${gameStore.turn}轮）`)
    return
  }
  
  showEndChatModal.value = true
}

// 确认结束对话
async function confirmEndChat() {
  try {
    // 1. 调用API
    await endChat(gameStore.sessionId)
    
    // 2. 更新状态
    sessionStore.startSurvey()
    gameStore.endedAt = new Date()
    
    // 3. 关闭WebSocket
    disconnect()
    
    // 4. 跳转到问卷页
    router.push('/survey')
    
  } catch (error) {
    console.error('结束对话失败:', error)
  }
}

// 组件挂载
onMounted(() => {
  // 建立WebSocket连接
  const wsUrl = `${import.meta.env.VITE_WS_BASE_URL}/chat/${sessionStore.sessionId}`
  connect(wsUrl)
  
  // 注册消息处理器
  onMessage('chat', handleReceiveMessage)
  onMessage('typing', handleTyping)
  onMessage('stop_typing', handleStopTyping)
  onMessage('session_ended', handleSessionEnded)
})

// 组件卸载
onUnmounted(() => {
  disconnect()
})

// 监听消息列表变化，自动滚动
watch(() => gameStore.messages, () => {
  scrollToBottom()
}, { deep: true })
</script>
```

### 5.2 问卷提交代码示例

```typescript
// Survey.vue
<script setup lang="ts">
import { ref, reactive } from 'vue'
import { useRouter } from 'vue-router'
import { useUserStore } from '@/stores/user'
import { useSessionStore } from '@/stores/session'
import { submitSurvey } from '@/api/survey'
import { ElMessage } from 'element-plus'

const router = useRouter()
const userStore = useUserStore()
const sessionStore = useSessionStore()

// 问卷数据
const formData = reactive({
  user_guess: 'human' as 'human' | 'ai' | 'unsure',
  confidence_level: 'mid' as 'low' | 'mid' | 'high',
  fluency_rating: 3,
  reason: '',
  self_role: 'other' as 'prover' | 'interferer' | 'other',
  strategy: ''
})

// 提交问卷
async function handleSubmit() {
  try {
    // 1. 前端验证
    if (!formData.user_guess) {
      ElMessage.error('请选择对方身份')
      return
    }
    
    if (!formData.confidence_level) {
      ElMessage.error('请选择信心等级')
      return
    }
    
    // 2. 调用API
    const result = await submitSurvey({
      sessionId: sessionStore.sessionId,
      userGuess: formData.user_guess,
      confidenceLevel: formData.confidence_level,
      fluencyRating: formData.fluency_rating,
      reason: formData.reason,
      selfRole: formData.self_role,
      strategy: formData.strategy
    })
    
    // 3. 更新用户积分
    userStore.updateScore(result.score)
    userStore.incrementSessionCount()
    
    // 4. 保存结果到Session Store（用于结果页显示）
    sessionStore.surveyResult = result
    
    // 5. 跳转到结果页
    router.push('/result')
    
  } catch (error) {
    console.error('提交问卷失败:', error)
  }
}
</script>
```

## 六、错误处理机制

### 6.1 错误分类

#### 1. 网络错误
- 连接超时
- 网络断开
- DNS解析失败

#### 2. 服务器错误
- 500 Internal Server Error
- 502 Bad Gateway
- 503 Service Unavailable

#### 3. 业务错误
- 400 Bad Request（参数错误）
- 401 Unauthorized（未登录）
- 403 Forbidden（无权限）
- 404 Not Found（资源不存在）
- 409 Conflict（邀请码已使用）

#### 4. WebSocket错误
- 连接失败
- 连接断开
- 消息格式错误

### 6.2 错误处理流程

```
错误发生
    ↓
┌─────────────────────┐
│ 错误拦截器捕获     │
└──────┬──────────────┘
       ↓
┌─────────────────────┐
│ 判断错误类型       │
└──────┬──────────────┘
       ↓
┌─────────────────────┐
│ 网络错误？        │
├──────┬──────────────┤
│ 是   │ 否          │
├──────┴──────┬───────┘
│             ↓
│ ┌─────────────────────┐
│ │ 显示"网络连接失败"  │
```

```typescript
// api/axios.ts - HTTP错误处理
axiosInstance.interceptors.response.use(
  (response: AxiosResponse) => {
    return response.data
  },
  (error) => {
    // 统一错误处理
    if (error.response) {
      // 服务器返回了错误状态码
      switch (error.response.status) {
        case 400:
          ElMessage.error('请求参数错误')
          break
        case 401:
          ElMessage.error('未授权，请重新登录')
          // 跳转到登录页
          router.push('/login')
          break
        case 403:
          ElMessage.error('拒绝访问')
          break
        case 404:
          ElMessage.error('请求资源不存在')
          break
        case 409:
          ElMessage.error(error.response.data.message || '操作冲突')
          break
        case 500:
        case 502:
        case 503:
          ElMessage.error('服务器错误，请稍后重试')
          break
        default:
          ElMessage.error('网络错误')
      }
    } else if (error.request) {
      // 请求已发送但未收到响应
      ElMessage.error('网络连接失败，请检查网络设置')
    } else {
      // 请求配置错误
      ElMessage.error('请求失败')
    }
    
    return Promise.reject(error)
  }
)

// composables/useWebSocket.ts - WebSocket错误处理
export function useWebSocket() {
  const ws = ref<WebSocket | null>(null)
  const isConnected = ref(false)
  const reconnectCount = ref(0)
  const MAX_RECONNECT_ATTEMPTS = 3
  
  function connect(url: string) {
    ws.value = new WebSocket(url)
    
    ws.value.onopen = () => {
      isConnected.value = true
      reconnectCount.value = 0
      console.log('WebSocket连接成功')
    }
    
    ws.value.onmessage = (event) => {
      const data = JSON.parse(event.data)
      handleMessage(data)
    }
    
    ws.value.onerror = (error) => {
      console.error('WebSocket错误:', error)
      ElMessage.error('连接错误，正在尝试重连...')
    }
    
    ws.value.onclose = () => {
      isConnected.value = false
      console.log('WebSocket连接断开')
      
      // 尝试重连
      if (reconnectCount.value < MAX_RECONNECT_ATTEMPTS) {
        reconnectCount.value++
        setTimeout(() => {
          console.log(`第${reconnectCount.value}次重连...`)
          connect(url)
        }, 2000 * reconnectCount.value)
      } else {
        ElMessage.error('连接失败，请刷新页面重试')
        // 跳转到大厅
        router.push('/lobby')
      }
    }
  }
  
  function disconnect() {
    if (ws.value) {
      ws.value.close()
      ws.value = null
    }
    isConnected.value = false
    reconnectCount.value = 0
  }
  
  return {
    isConnected,
    connect,
    disconnect,
    send,
    onMessage
  }
}
```

```typescript
// utils/analytics.ts
interface AnalyticsEvent {
  event_type: string
  event_data: any
  timestamp: number
  session_id: string
}

const eventQueue: AnalyticsEvent[] = []
const BATCH_SIZE = 10
const BATCH_INTERVAL = 5000 // 5秒

// 添加事件到队列
function trackEvent(eventType: string, eventData: any = {}) {
  const event: AnalyticsEvent = {
    event_type: eventType,
    event_data: eventData,
    timestamp: Date.now(),
    session_id: getCurrentSessionId()
  }
  
  eventQueue.push(event)
  
  // 达到批量大小或定时上传
  if (eventQueue.length >= BATCH_SIZE) {
    uploadEvents()
  }
}

// 批量上传事件
async function uploadEvents() {
  if (eventQueue.length === 0) return
  
  try {
    const eventsToUpload = [...eventQueue]
    eventQueue.length = 0 // 清空队列
    
    await axios.post('/api/analytics', { events: eventsToUpload })
    
  } catch (error) {
    console.error('上传分析数据失败:', error)
    // 失败的重新放回队列
    eventQueue.unshift(...eventsToUpload)
  }
}

// 定时上传
setInterval(uploadEvents, BATCH_INTERVAL)

// 使用示例
trackEvent('button_click', { button_id: 'start_match' })
trackEvent('message_sent', { length: 50, is_meta: true })
trackEvent('page_view', { page: 'chat', duration: 30000 })
```

## 八、总结

### 8.1 数据流特点

1. **清晰的层次**：UI层 → 状态层 → 逻辑层 → 数据层 → 后端
2. **响应式驱动**：状态变化自动触发UI更新
3. **实时性**：WebSocket保证实时通信
4. **容错性**：完善的错误处理和重连机制
5. **数据完整**：完整记录用户行为用于研究

### 8.2 优化建议

1. **减少不必要的状态更新**：使用computed、watch等优化性能
2. **批量上传**：分析数据批量上传，减少请求次数
3. **本地缓存**：常用数据本地缓存，减少网络请求
4. **错误重试**：关键操作支持自动重试
5. **离线支持**：重要操作支持离线队列
