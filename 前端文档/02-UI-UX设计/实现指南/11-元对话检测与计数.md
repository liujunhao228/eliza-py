# 元对话检测与计数

## 文档说明

本文档详细说明元对话检测与计数机制的实现，这是图灵测试实验平台的核心博弈功能之一。

---

## 一、功能概述

### 1.1 元对话定义

元对话指在对话中讨论身份、真人/机器等话题的行为。这是博弈论中的双刃剑机制：
- **收益**：提高奖励倍数（判断正确时获得更高分数）
- **风险**：增加惩罚倍数（判断错误时损失更多分数）
- **策略**：用户需要权衡风险与收益，做出最优决策

### 1.2 核心机制

```
元对话次数增加 → 倍数提高 → 潜在收益增加 + 潜在风险增加
```

**倍数计算公式**：
- 正确倍数 = 1 + (元对话次数 × 0.2)
- 惩罚倍数 = 1 + (元对话次数 × 0.3)

**示例**：
- 3次元对话：正确倍数 ×1.6，惩罚倍数 ×1.9
- 5次元对话：正确倍数 ×2.0，惩罚倍数 ×2.5

## 二、Composable实现

### 2.1 useMetaConversation.ts

```typescript
// composables/useMetaConversation.ts
import { computed } from 'vue'
import { useGameStore } from '@/stores/game'

// 元对话关键词列表
const META_KEYWORDS = [
  // 身份相关
  '真人', '机器', 'AI', '机器人', '人工智能', 
  '程序', '算法', '人类', '人', '电脑', '计算',
  
  // 询问身份
  '你是', '我是', '身份', '真假', '还是', '到底',
  
  // 判断表达
  '我觉得', '我认为', '应该是', '看起来像'
]

export function useMetaConversation() {
  const gameStore = useGameStore()

  // 检测是否为元对话
  function isMetaConversation(message: string): boolean {
    if (!message) return false
    
    const lowerMessage = message.toLowerCase()
    
    // 检查是否包含元对话关键词
    return META_KEYWORDS.some(keyword => 
      lowerMessage.includes(keyword.toLowerCase())
    )
  }

  // 处理消息（检测并更新计数）
  function handleMessage(message: string, sender: 'user' | 'opponent'): boolean {
    const isMeta = isMetaConversation(message)
    
    // 如果是元对话，增加计数
    if (isMeta) {
      gameStore.incrementMetaCount()
      
      // 记录到消息中
      console.log(`[${sender}] 检测到元对话: ${message}`)
    }
    
    return isMeta
  }

  // 获取当前元对话次数
  const metaCount = computed(() => gameStore.metaConversationCount)

  // 获取当前倍数
  const multipliers = computed(() => ({
    correct: (1 + metaCount.value * 0.2).toFixed(1),
    penalty: (1 + metaCount.value * 0.3).toFixed(1)
  }))

  // 判断是否高频元对话（>5次）
  const isHighFrequency = computed(() => metaCount.value > 5)

  return {
    isMetaConversation,
    handleMessage,
    metaCount,
    multipliers,
    isHighFrequency
  }
}
```

## 六、数据采集

### 6.1 记录元对话事件

```typescript
// utils/analytics.ts
export function trackMetaConversation(
  sender: 'user' | 'opponent',
  message: string,
  currentCount: number
) {
  trackEvent('meta_conversation', {
    sender,
    message,
    current_count: currentCount,
    timestamp: Date.now()
  })
}

// 在handleMessage中使用
function handleMessage(message: string, sender: 'user' | 'opponent'): boolean {
  const isMeta = isMetaConversation(message)
  
  if (isMeta) {
    gameStore.incrementMetaCount()
    
    // 记录研究数据
    trackMetaConversation(sender, message, gameStore.metaConversationCount)
  }
  
  return isMeta
}
```
