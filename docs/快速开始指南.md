# Alice 项目快速开始指南

## 🚀 5 分钟快速上手

### 1. 环境准备

```bash
# 克隆或进入项目目录
cd F:\eliza-py

# 安装依赖（仅需 jieba）
pip install -r requirements.txt
```

**依赖说明**:
- `jieba`: 中文分词工具（约 3MB，可选，未安装时自动使用基础模式）
- 其他依赖均为开发工具，按需安装

### 2. 开始对话

```bash
# 运行 Alice
python alice/core.py
```

**示例对话**:
```
Alice: 你好！我是 Alice，你的好奇朋友。有什么想聊的吗？
你：我昨天去了一个新开的餐厅
Alice: 后来呢？发生了什么让你印象深刻的事吗？
你：那里的装修很有特色
Alice: 听起来很有意思，能详细说说吗？
你：服务员也很热情
Alice: 哇，那一定很有趣吧？继续说说看！
```

### 3. 编程使用

```python
from alice.core import AliceBot

# 初始化机器人
alice = AliceBot()

# 方式 1: 简单对话
response = alice.respond("你好")
print(response)  # 输出：你好！很高兴和你聊天。

# 方式 2: 多轮对话
conversation = [
    "我最近工作压力很大",
    "总是加班到很晚",
    "感觉身体吃不消了"
]

for msg in conversation:
    response = alice.respond(msg)
    print(f"Alice: {response}")

# 方式 3: 获取对话摘要
summary = alice.get_conversation_summary()
print(f"对话轮数：{summary['turns']}")
print(f"提及的实体：{summary['recent_entities']}")
```

## 🔧 核心概念

### 1. 对话处理流程

```
用户输入 → 预处理 → 语义分析 → 脚本匹配 → 响应生成 → 输出
```

- **预处理**: 文本标准化、全半角转换
- **语义分析**: 分词、情感分析、意图识别
- **脚本匹配**: 根据意图匹配响应模板
- **响应生成**: 选择最合适的回复

### 2. 脚本系统

Alice 的行为由 `curiosity_scripts.json` 控制，包含：

| 意图类别 | 描述 | 示例 |
|---------|------|------|
| greeting | 问候回应 | "你好" → "你好呀！" |
| narrative_continuation | 叙事延续 | "我去了..." → "后来呢？" |
| person_focus | 人物关注 | "我朋友..." → "ta 是个怎样的人？" |
| emotional_expression | 情感表达 | "我很难过" → "愿意聊聊吗？" |
| self_thought | 自我反思 | "我觉得..." → "为什么这样想？" |
| default | 默认回应 | 其他 → "能再多聊聊吗？" |

### 3. 反射转换

Alice 会将用户的话语进行"反射"转换：

```
用户：我妈妈不理解我
Alice: 你妈妈不理解你？（代词转换 + 反问）
```

## 🛠️ 自定义配置

### 1. 修改响应风格

编辑 `alice/scripts/curiosity_scripts.json`:

```json
{
  "narrative_continuation": {
    "patterns": [".*去.*了.*"],
    "responses": [
      "你的自定义响应 1",
      "你的自定义响应 2"
    ],
    "priority": 5
  }
}
```

### 2. 添加新意图

在脚本文件中添加新类别：

```json
{
  "new_intent": {
    "patterns": ["你的匹配模式"],
    "responses": ["响应 1", "响应 2"],
    "priority": 4
  }
}
```

### 3. 调整优先级

- `priority: 6-7`: 高优先级（问候、紧急）
- `priority: 4-5`: 中优先级（叙事、情感）
- `priority: 1-3`: 低优先级（通用回应）

## 🔧 常见问题

### Q1: 为什么响应有时候不准确？
A: Alice 使用基于规则的匹配，如果响应不理想，可以：
- 检查脚本中的 pattern 是否匹配你的输入
- 添加更多响应变体增加多样性
- 调整优先级确保正确的脚本被匹配

### Q2: 如何让 Alice 更"聪明"？
A: 可以可选安装 NLP 增强：
```bash
# 安装 LTP（深度句法分析）
pip install ltp==4.2.10

# 安装 sentence-transformers（语义相似度）
pip install sentence-transformers==2.2.2
```

### Q3: 响应时间慢怎么办？
A: 
- 确保已安装 jieba（加速分词）
- 避免使用大型 NLP 模型（除非必要）
- 限制对话历史长度

### Q4: 如何集成到我的项目？
A:
```python
from alice.core import AliceBot

class MyApplication:
    def __init__(self):
        self.alice = AliceBot(script_file="path/to/custom_script.json")
    
    def handle_message(self, user_input):
        return self.alice.respond(user_input)
```
