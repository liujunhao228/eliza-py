# Alice 重组规则使用指南

## 概述

Alice 现已融合 Eliza 的重组规则（Reassembly Rules）机制，支持根据用户输入动态生成个性化响应。

## 重组规则语法

### 基础语法

重组规则使用 `{1}`, `{2}`, `{3}` 等占位符引用正则表达式匹配的捕获组：

```json
{
  "patterns": [".*(感到 | 觉得).*?(难过 | 开心).*"],
  "reassembly_rules": [
    "你为什么感到{2}呢？",
    "是什么让你{2}？",
    "这种{2}的感觉持续多久了？"
  ]
}
```

### 工作原理

```
用户输入："我感到很难过"
匹配模式：".*(感到 | 觉得).*?(难过 | 开心).*"
分解组件：["感到", "难过"]
重组规则："你为什么感到{2}呢？"
输出："你为什么感到难过呢？"
```

## 配置文件

### 1. 脚本配置 (`alice/scripts/curiosity_scripts.json`)

在脚本中添加 `reassembly_rules` 字段：

```json
{
  "emotional_expression": {
    "id": "emotional_expression",
    "name": "情感表达",
    "patterns": [".*(难过 | 开心 | 生气).*"],
    "responses": ["听起来你现在感受很复杂..."],
    "priority": 6,
    "reassembly_rules": [
      "你为什么感到{1}呢？",
      "是什么让你{1}？",
      "这种{1}的感觉是从什么时候开始的？"
    ]
  }
}
```

### 2. 反射规则配置 (`alice/scripts/reflection_rules.json`)

配置代词映射和句式转换规则：

```json
{
  "pronoun_mapping": {
    "我": "你",
    "我的": "你的",
    "我们": "你们"
  },
  "transformation_rules": [
    ["我觉得 (.*)", "你为什么觉得{1}呢？"],
    ["我不 (.*)", "为什么不{1}呢？"]
  ]
}
```

## 使用示例

### 基本使用

```python
from alice.core import AliceBot

alice = AliceBot()

# 普通对话（使用预设响应）
response = alice.respond("你好")
print(response)  # "你好呀！有什么想聊的吗？"

# 触发重组规则
response = alice.respond("我感到很疲惫")
print(response)  # "你为什么感到疲惫呢？"（动态生成）
```

### 自定义脚本文件

```python
from alice.core import AliceBot

# 加载自定义脚本和规则
alice = AliceBot(
    script_file="path/to/your_script.json",
    rules_file="path/to/your_rules.json"
)

response = alice.respond("我觉得工作压力很大")
print(response)
```

### 直接使用重组引擎

```python
from alice.utils.reassembly import ReassemblyEngine

engine = ReassemblyEngine()

# 基本重组
components = ["", "难过"]
rule = "你为什么感到{2}呢？"
result = engine.reassemble(components, rule)
print(result)  # "你为什么感到难过呢？"

# 带代词转换的重组
components = ["我", "压力很大"]
rule = "为什么{1}{2}呢？"
result = engine.reassemble(components, rule, apply_pronoun_mapping=True)
print(result)  # "为什么你压力很大呢？"
```

## 设计说明

### 重组规则 vs 预设响应

| 特性 | 重组规则 | 预设响应 |
|------|----------|----------|
| 个性化 | 高 - 引用用户原话 | 低 - 通用响应 |
| 自然度 | 高 - 动态组合 | 中 - 固定模板 |
| 配置复杂度 | 中 | 低 |
| 适用场景 | 情感表达、自我反思等 | 问候、默认回应等 |

### 何时使用重组规则

**推荐使用**的场景：
- 情感表达（"你为什么感到{1}呢？"）
- 自我反思（"你是怎么形成{1}的？"）
- 叙事延续（"后来{1}发生了什么？"）
- 人物关注（"你和{1}的关系怎么样？"）

**不推荐**的场景：
- 简单问候（"你好"）
- 通用回应（"嗯，我明白了"）
- 固定回应（"再见"）

### 记忆堆栈决策

**不采用 Eliza 记忆堆栈**，原因：
- 中文对话中显得突兀
- 与"好奇朋友"角色定位冲突
- 现代用户期望自然流畅的对话

**替代方案**：使用 `DialogueContext` 轻量级追踪最近提及的实体。

## 最佳实践

### 1. 编写重组规则

```json
// 好的例子
{
  "reassembly_rules": [
    "你为什么感到{1}呢？",
    "是什么让你{1}？",
    "这种{1}的感觉持续多久了？"
  ]
}

// 避免过于复杂
{
  "reassembly_rules": [
    "考虑到你刚才说的{1}和{2}，我认为{3}是一个值得探讨的问题"
  ]
}
```

### 2. 规则数量

每个脚本类别建议配置 **3-5 条** 重组规则：
- 太少：容易重复
- 太多：配置复杂，收益递减

### 3. 代词转换

重组规则会自动应用代词转换：
- "我" → "你"
- "我的" → "你的"
- "我们" → "你们"

无需在规则中手动处理。

### 4. 避免重复

重组规则选择器会自动避免连续使用同一条规则：

```python
selector = ReassemblyRuleSelector(rules)
rule1 = selector.select(avoid_repeats=True)  # 选择规则 1
rule2 = selector.select(avoid_repeats=True)  # 选择规则 2（非规则 1）
```

## 故障排除

### 问题：重组规则未生效

**检查清单**：
1. 脚本中是否包含 `reassembly_rules` 字段
2. 正则 `patterns` 是否包含捕获组 `()`
3. 重组规则中的占位符 `{1}`, `{2}` 是否与捕获组对应

### 问题：代词转换未生效

确保 `apply_pronoun_mapping=True`（默认值）：

```python
engine.reassemble(components, rule, apply_pronoun_mapping=True)
```

### 问题：响应重复

检查是否配置了足够的重组规则（建议 3-5 条），并确保 `avoid_repeats=True`。
