# 脚本编写指南

> 本指南介绍如何在Alice中编写脚本

### A. 依存关系标注集

| 标签 | 说明 | 示例 |
|------|------|------|
| SBV | 主谓关系 | 我←→喜欢 |
| VOB | 动宾关系 | 喜欢←→你 |
| IOB | 间宾关系 | 给←→我←→书 |
| ATT | 定中关系 | 美丽←→的花 |
| ADV | 状中结构 | 非常←→好 |
| CMP | 动补结构 | 跑←→快 |
| COO | 并列关系 | 你←→和←→我 |
| POB | 介宾关系 | 在←→家里 |
| LAD | 左附加关系 | 第←→一 |
| RAD | 右附加关系 | 孩子←→们 |
| IS | 独立结构 | 啊，←→真好 |
| HED | 核心关系 | ROOT←→谓语 |

### B. 词性标注集（PKU 标准）

| 标签 | 说明 | 示例 |
|------|------|------|
| n | 名词 | 书、学生 |
| v | 动词 | 跑、学习 |
| a | 形容词 | 好、美丽 |
| d | 副词 | 很、非常 |
| r | 代词 | 我、你 |
| m | 数词 | 一、二 |
| q | 量词 | 个、只 |
| p | 介词 | 在、从 |
| c | 连词 | 和、或 |
| u | 助词 | 的、了 |
| nh | 人名 | 张三 |
| ni | 机构名 | 清华大学 |
| ns | 地名 | 北京 |
