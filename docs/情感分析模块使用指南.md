# 情感分析模块使用指南

## 概述

Alice 项目的情感分析模块提供了多种情感分析引擎，支持从轻量级规则词典到深度学习模型的不同精度需求。

## 特性

- **多引擎支持**: 规则词典、BERT、SnowNLP 三种引擎
- **细粒度情感**: 支持喜、怒、哀、惧、焦虑、厌恶、惊讶等情感分类
- **程度副词识别**: 自动识别"非常"、"有点"等程度副词并调整情感强度
- **否定词处理**: 智能处理否定词对情感的影响
- **降级处理**: 高级引擎不可用时自动降级到规则引擎

## 快速开始

### 基础使用

```python
from alice.nlp.sentiment import create_sentiment_engine

# 创建规则引擎（轻量级，无需额外依赖）
engine = create_sentiment_engine(mode='rule')

# 分析文本
result = engine.analyze("我很开心")

print(f"情感分数：{result.score}")      # 1.0
print(f"情感标签：{result.label}")      # SentimentLabel.POSITIVE
print(f"置信度：{result.confidence}")    # 1.0
print(f"情感关键词：{result.keywords}")  # ['开心']
print(f"细粒度情感：{result.emotions}")  # {'joy': 1.0}
```

### 使用 BERT 引擎（高精度）

```python
# 需要先安装：pip install transformers torch
engine = create_sentiment_engine(mode='bert', lazy_load=True)
result = engine.analyze("我感到很沮丧")
print(f"情感分数：{result.score}")
```

### 使用 SnowNLP 引擎（折中方案）

```python
# 需要先安装：pip install snownlp
engine = create_sentiment_engine(mode='snownlp')
result = engine.analyze("这真是太棒了")
print(f"情感分数：{result.score}")
```

### 自动选择引擎

```python
# 自动选择最佳可用引擎（优先级：BERT > SnowNLP > Rule）
engine = create_sentiment_engine(mode='auto')
result = engine.analyze("心情不错")
```

### 混合引擎模式

```python
# 融合多个引擎的结果，提高准确性
engine = create_sentiment_engine(
    mode='hybrid',
    engines=['rule', 'snownlp'],
    weights={'rule': 0.4, 'snownlp': 0.6}
)
result = engine.analyze("心情复杂")
```

## 情感分析结果

### SentimentResult 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| text | str | 原始文本 |
| score | float | 情感分数 (-1.0 到 1.0) |
| label | SentimentLabel | 情感标签 (positive/negative/neutral/mixed) |
| confidence | float | 置信度 (0.0 到 1.0) |
| emotions | Dict[str, float] | 细粒度情感强度 |
| keywords | List[str] | 情感关键词 |
| metadata | Dict | 额外元数据 |

### 情感标签

- `SentimentLabel.POSITIVE`: 正面情感
- `SentimentLabel.NEGATIVE`: 负面情感
- `SentimentLabel.NEUTRAL`: 中性情感
- `SentimentLabel.MIXED`: 混合情感

### 细粒度情感类型

- `joy`: 喜悦
- `anger`: 愤怒
- `sadness`: 悲伤
- `fear`: 恐惧
- `anxiety`: 焦虑
- `disgust`: 厌恶
- `surprise`: 惊讶

## 高级用法

### 获取情感强度

```python
engine = create_sentiment_engine(mode='rule')

result1 = engine.analyze("我非常开心")
result2 = engine.analyze("有点开心")

print(engine.get_intensity(result1))  # "strong"
print(engine.get_intensity(result2))  # "weak"
```

### 获取情感描述

```python
result = engine.analyze("我很愤怒")
description = engine.get_emotion_description(result)
print(description)  # "非常生气"
```

### 批量分析

```python
texts = ["我很开心", "我很难过", "心情一般"]
results = engine.analyze_batch(texts)

for text, result in zip(texts, results):
    print(f"{text}: {result.label.value} ({result.score})")
```

### 自定义情感词库

```python
engine = create_sentiment_engine(mode='rule')

# 添加正面词
engine.add_positive_words({"优秀", "出色"})

# 添加负面词
engine.add_negative_words({"糟糕", "差劲"})

result = engine.analyze("表现优秀")
print(result.score)  # 正数
```

## 在 Alice 对话系统中的集成

情感分析模块已集成到 Alice 对话系统中，自动根据用户输入的情感生成共情回应：

```python
from alice.alice_v2 import AliceBot

alice = AliceBot(use_ltp=False, sentiment_mode='rule')

# 用户输入负面情感内容
response = alice.respond("我今天很难过")
# Alice 会回应："听起来那阵子你挺不容易的，那种感觉现在还在吗？"

# 用户输入正面情感内容
response = alice.respond("我升职了！")
# Alice 会回应："哇，听得出你现在心情不错！这种好心情是因为什么呢？"
```

## 性能对比

| 引擎 | 速度 | 精度 | 依赖 | 适用场景 |
|------|------|------|------|----------|
| 规则词典 | 快 | 中 | 无 | 实时对话、资源受限环境 |
| BERT | 慢 | 高 | transformers, torch | 高精度需求、离线分析 |
| SnowNLP | 中 | 中 | snownlp | 平衡速度和精度 |
| 混合模式 | 中 | 中高 | 可选 | 需要鲁棒性的场景 |

## 故障排除

### 情感分析结果始终为中性

检查输入文本是否包含情感词。规则引擎基于词典匹配，如果文本中没有已知的情感词，将返回中性结果。

### BERT 引擎加载失败

1. 确认已安装依赖：`pip install transformers torch`
2. 检查网络连接（首次使用需要下载模型）
3. 使用懒加载模式：`create_sentiment_engine(mode='bert', lazy_load=True)`

### 程度副词未生效

确保程度副词和情感词同时出现在文本中，例如"非常开心"而不是分开的"非常"和"开心"。

## API 参考

### create_sentiment_engine(mode, **kwargs)

创建情感分析引擎的工厂函数。

**参数:**
- `mode` (str): 引擎模式 ('rule', 'bert', 'snownlp', 'auto', 'hybrid')
- `**kwargs`: 传递给具体引擎的参数

**返回:**
- SentimentEngine 实例

### SentimentEngine.analyze(text)

分析文本情感。

**参数:**
- `text` (str): 待分析文本

**返回:**
- SentimentResult 实例

## 扩展情感词库

可以通过 YAML 配置文件扩展情感词库：

```yaml
# custom_emotions.yaml
positive_words:
  - "给力的"
  - "赞"
  - "牛逼"

negative_words:
  - "拉胯"
  - "无语"
  - "emo"
```

然后加载配置：

```python
import yaml
from alice.nlp.sentiment import RuleSentimentEngine

with open('custom_emotions.yaml', 'r', encoding='utf-8') as f:
    config = yaml.safe_load(f)

engine = RuleSentimentEngine(
    custom_positive=set(config['positive_words']),
    custom_negative=set(config['negative_words'])
)
```
