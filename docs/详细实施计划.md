# Alice 程序详细实施计划（修订版）

## 📋 项目目标

**核心目标**: 实现一个轻量化、快速响应的中文版"好奇的朋友"聊天机器人

**具体指标**（调整后）:
- ✅ 能够主动询问细节问题（如"后来呢？""为什么？"）
- ✅ 识别对话中的关键人物、事件、情感
- ✅ 保持 3 轮左右的上下文记忆
- ✅ 响应时间控制在 **2 秒以内**（原 500ms 调整为务实目标）
- ✅ 对话自然度≥70%（通过用户主观评估）

## 🛠️ 技术栈选择（轻量化方案）

### 核心依赖（必需）
```
jieba==0.42.1       # 中文分词，轻量级且快速
```

### 可选增强（Phase 2+）
```
# 以下依赖在基础版本稳定后按需添加
# ltp==4.2.10                    # 深度句法分析（首次加载慢）
# sentence-transformers==2.2.2   # 语义相似度（模型体积大）
```

### 技术选型理由
1. **jieba**: 仅 3MB，分词速度快（<10ms），满足基础需求
2. **规则引擎优先**: 先实现基于模式匹配的可靠系统，再考虑 NLP 增强
3. **渐进式增强**: 基础版本稳定后，可选择性添加高级功能

# tests/test_performance.py
import time
from alice.core import AliceBot

def performance_test():
    alice = AliceBot()
    
    test_inputs = [
        "你好",
        "我昨天去了公园",
        "遇到了一个有趣的人",
        "我们一起聊了很久",
        "感觉时间过得很快",
    ]
    
    start_time = time.time()
    for inp in test_inputs:
        response = alice.respond(inp)
        print(f"输入：{inp} -> 响应：{response}")
    end_time = time.time()
    
    avg_time = (end_time - start_time) / len(test_inputs) * 1000
    print(f"平均响应时间：{avg_time:.2f}ms")
    
    # 目标：平均响应时间 < 2000ms
    assert avg_time < 2000, f"响应时间过长：{avg_time}ms"

if __name__ == '__main__':
    performance_test()

## 🔧 常见问题解决

### Q1: 响应不够自然怎么办？
```python
# 解决方案：添加语气词和响应变化
def _post_process_response(self, response: str) -> str:
    # 30% 概率添加语气词
    if random.random() < 0.3:
        prefixes = ["嗯...", "诶？", "真的吗？", "这样啊..."]
        response = random.choice(prefixes) + response
    return response
```

### Q2: 如何避免重复响应？
```python
# 解决方案：响应历史记忆
self.last_used_responses = {}

def match_script(self, text: str):
    # 避免使用最近用过的响应
    available = [r for r in responses if r != last_response]
    return random.choice(available)
```

### Q3: 如何处理未知输入？
```python
# 解决方案：多层降级策略
def respond(self, user_input: str):
    # 1. 尝试脚本匹配
    response = self.script_engine.match_script(user_input)
    if response:
        return response
    
    # 2. 尝试反射转换
    response = self.reflection_engine.transform(user_input)
    if response != user_input:
        return response + "？"
    
    # 3. 通用回应
    return self._generic_response()
```
