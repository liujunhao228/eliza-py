# Alice 程序设计方案（修订版）

## 📋 项目概述

**项目名称**: Alice - 好奇的朋友  
**设计理念**: 基于 ELIZA 经典的"镜像反射"原理，采用轻量化设计实现中文对话机器人  
**角色定位**: 一个永远对你充满好奇的朋友，常用"为什么"和"然后呢"引导对话

## 🏗️ 系统架构设计

### 1. 核心处理管线（简化版）

```
用户输入 → 预处理 → 语义分析 → 脚本匹配 → 反射转换 → 响应生成 → 输出
```

**设计原则**:
- **轻量化优先**: 不依赖大型 NLP 模型
- **规则驱动**: 基于正则表达式和模式匹配
- **渐进增强**: 基础版本稳定后可选加 NLP 功能

### 2. 模块划分

#### 2.1 输入预处理模块 (Preprocessing Module)
- **功能**: 文本标准化、全半角转换、标点统一
- **技术**: 正则表达式、字符映射
- **输出**: 标准化的中文文本
- **性能**: <10ms

#### 2.2 语义分析模块 (Semantic Analysis Module)
- **功能**: 分词、情感分析、意图识别、实体提取
- **技术**: jieba 分词 + 规则引擎
- **输出**: 语义分析结果（tokens、sentiment、intent、entities）
- **性能**: <50ms

#### 2.3 反射转换引擎 (Reflection Engine)
- **功能**: 代词转换、语序调整、句式重构
- **核心技术**:
  - 代词映射表（可配置，见 `alice/scripts/reflection_rules.json`）
  - 句式转换规则（我觉得→你为什么觉得）
  - 中文特殊语法处理
- **重组规则支持**: 支持 Eliza 风格的组件引用语法 `{1}`, `{2}` 等
- **性能**: <20ms

> 📝 **注意**: 反射规则的详细设计见 [重组规则融合方案](./Alice 融合 Eliza 重组规则设计方案.md)

#### 2.4 好奇心脚本系统 (Curiosity Script System)
- **功能**: 基于意图的对话引导
- **核心逻辑**:
  - 叙事助推器 (Narrative Booster) - "后来呢？"
  - 人物关注 (Person Focus) - "ta 是个怎样的人？"
  - 情感回声 (Emotional Echo) - "这种感受从哪来的？"
  - 观点询问 (Opinion Question) - "你怎么看？"
- **响应模板**: 每类 5-12 个变体，避免重复

#### 2.5 上下文记忆系统 (Context Memory System)
- **功能**: 会话状态维护、关键实体追踪
- **实现**: FIFO 队列存储最近 3 个实体
- **应用**: 自然引用之前话题（如"你刚才提到的朋友..."）
- **设计说明**: 不采用 Eliza 的记忆堆栈机制，详见 [重组规则融合方案](./Alice 融合 Eliza 重组规则设计方案.md)

## 🔧 技术实现

### 1. 轻量化语义分析

```python
class SemanticAnalyzer:
    def __init__(self):
        # 情感词库（简化版）
        self.positive_words = {'好', '棒', '喜欢', '开心', '高兴'}
        self.negative_words = {'坏', '差', '讨厌', '难过', '生气'}
        
        # 意图关键词映射
        self.intent_keywords = {
            'narrative': ['去', '做', '看', '买', '发生'],
            'emotion': ['感觉', '觉得', '心情', '感受'],
            'person': ['朋友', '家人', '同事', '老板'],
        }
    
    def analyze(self, text: str) -> Dict:
        words = list(jieba.cut(text))
        
        return {
            'tokens': words,
            'sentiment': self._analyze_sentiment(words),
            'intent': self._detect_intent(words),
            'entities': self._extract_entities(words),
        }
```

### 2. 反射转换引擎

```python
class ReflectionEngine:
    def __init__(self):
        self.pronoun_mapping = {
            '我': '你', '我的': '你的', '我们': '你们',
            '我妈': '你妈', '我爸': '你爸', '我朋友': '你朋友',
        }
        
        self.transformation_rules = [
            (r'我觉得 (.*)', r'你为什么觉得\1 呢？'),
            (r'我不 (.*)', r'为什么不\1 呢？'),
            (r'我想 (.*)', r'为什么想\1 呢？'),
        ]
    
    def transform(self, text: str) -> str:
        # 1. 代词映射
        transformed = text
        for pronoun, replacement in self.pronoun_mapping.items():
            transformed = transformed.replace(pronoun, replacement)
        
        # 2. 句式转换
        for pattern, replacement in self.transformation_rules:
            if re.search(pattern, transformed):
                transformed = re.sub(pattern, replacement, transformed)
                break
        
        return transformed
```

### 4. 对话引擎主流程

```python
class AliceBot:
    def respond(self, user_input: str) -> str:
        # 1. 预处理
        text = self.preprocessor.standardize_text(user_input)
        
        # 2. 语义分析
        semantic_info = self.analyzer.analyze(text)
        
        # 3. 脚本匹配
        response = self.script_engine.match_script(text, semantic_info)
        if response:
            return response
        
        # 4. 反射转换（备选）
        reflected = self.reflection_engine.transform(text)
        if reflected != user_input:
            return f"{reflected}？"
        
        # 5. 通用回应
        return self._generic_response()
```

## 📊 脚本设计

### 意图类别（11 类）

| 类别 | 描述 | 触发示例 | 响应示例 |
|------|------|----------|----------|
| greeting | 问候回应 | "你好"、"嗨" | "你好！很高兴和你聊天" |
| narrative_continuation | 叙事延续 | "我去了..."、"发生了..." | "后来呢？" |
| person_focus | 人物关注 | "我朋友..."、"他..." | "ta 是个怎样的人？" |
| emotional_expression | 情感表达 | "我很难过"、"很开心" | "这种感受从哪来的？" |
| opinion_question | 观点询问 | "为什么..."、"怎么..." | "你怎么看？" |
| relationship_discussion | 关系讨论 | "我们关系..."、"吵架了" | "这段关系对你意味着什么？" |
| work_study | 工作学习 | "工作压力大"、"考试..." | "有什么让你有成就感的？" |
| past_experience | 过去经历 | "以前..."、"记得..." | "那段经历对你有什么影响？" |
| future_plan | 未来计划 | "打算..."、"希望..." | "你打算怎么实现？" |
| self_reflection | 自我反思 | "我觉得..."、"我认为..." | "为什么会有这种想法？" |
| default | 默认回应 | 其他所有 | "能再多聊聊吗？" |

### 响应设计原则

1. **好奇心驱动**: 多问"为什么"、"然后呢"、"怎么想的"
2. **避免说教**: 不给建议，只引导用户自己思考
3. **情感验证**: 先认可感受，再询问细节
4. **多样性**: 每类 5-12 个响应变体，避免重复
5. **自然口语**: 使用"诶？"、"嗯..."、"真的吗？"等语气词

## 🎯 核心算法设计

### 1. 脚本匹配算法
```
输入：用户话语
↓
遍历脚本（按优先级降序）
↓
正则匹配 pattern
↓
匹配成功 → 选择响应（避免重复）
↓
输出：机器人回复
```

### 2. 反射转换算法
```
输入：用户原始话语
↓
代词映射（按长度降序匹配）
↓
句式规则匹配
↓
应用转换规则
↓
输出：转换后的话语
```

### 3. 上下文管理算法
```
输入：当前对话 + 历史上下文
↓
提取实体（人称、时间、地点）
↓
更新 FIFO 队列（最多 3 个）
↓
检测话题延续性
↓
输出：更新后的上下文
```

## 📈 性能优化策略

### 1. 响应时间控制
- 预加载脚本配置
- 正则表达式预编译
- 限制上下文记忆长度

### 2. 内存管理
- 限制对话历史记录（最近 10 轮）
- 定期清理过期上下文
- 避免大量中间变量

### 3. 响应多样性
- 响应历史记忆（避免连续重复）
- 随机语气词添加（30% 概率）
- 响应模板轮换机制

## 🔒 质量保障措施

### 1. 鲁棒性设计
- 输入验证（空输入、超长输入）
- 异常捕获和降级
- 优雅的错误提示

### 2. 用户体验优化
- 加入语气助词（"诶？"、"真的吗？"）
- 控制重复响应频率
- 响应长度适中（10-50 字）

### 3. 角色定位维持
- 严格限制生成式回复
- 保持"好奇朋友"而非"专家"的角色
- 避免过度解读用户话语
