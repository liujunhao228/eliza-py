## 🚀 快速开始

### 环境要求

- Python 3.7 或更高版本
- 操作系统：Windows / macOS / Linux

### 安装步骤

**1. 获取项目**

```bash
# 方式 1: 克隆 Git 仓库
git clone <项目地址>
cd eliza-py

# 方式 2: 下载 ZIP 文件并解压
```

**2. 安装依赖**

```bash
# 基础安装（推荐）
pip install -r requirements.txt

# 最小安装（仅必需依赖）
pip install jieba
```

**3. 验证安装**

```bash
python alice/core.py
```

如果看到 `Alice: 你好！我是 Alice...` 提示，说明安装成功。

## 💬 功能介绍

### 核心特性

| 特性 | 说明 |
|------|------|
| 🎯 好奇心驱动 | 主动询问"为什么"、"然后呢"引导对话 |
| 🔄 镜像反射 | 将用户的话语转换后反问，促进自我思考 |
| 📝 上下文记忆 | 记住最近提到的关键人物和事件 |
| ⚡ 快速响应 | 平均响应时间 <200ms |
| 🔧 易于定制 | JSON 配置文件调整行为 |

### 对话能力

Alice 可以理解和回应以下类型的对话：

#### 1. 问候
```
你：你好
Alice: 你好！很高兴和你聊天。
```

#### 2. 分享经历
```
你：我昨天去了一个新开的餐厅
Alice: 后来呢？发生了什么让你印象深刻的事吗？
```

#### 3. 讨论人物
```
你：我朋友总是针对我
Alice: 你觉得 ta 为什么会这样做呢？
```

#### 4. 表达情感
```
你：最近工作压力很大，感觉很累
Alice: 是什么让你产生了这样的情绪呢？
```

#### 5. 寻求建议
```
你：我不知道该怎么办
Alice: 对于这个问题，你自己有什么想法吗？
```

## 📱 使用方式

### 方式一：命令行对话

**启动程序**
```bash
python alice/core.py
```

**对话示例**
```
Alice: 你好！我是 Alice。有什么想聊的吗？
Alice: 输入 'quit' 或 '再见' 结束对话。

你：我今天心情不太好
Alice: 听起来你现在感受很复杂，能跟我说说具体是什么让你有这样的感受吗？

你：工作上遇到了一些问题
Alice: 工作上的问题确实让人烦恼。具体是什么让你感到困扰呢？

你：再见
Alice: 再见！很高兴和你聊天！
```

**可用命令**
| 命令 | 功能 |
|------|------|
| `quit` / `exit` / `bye` / `再见` | 结束对话 |
| `Ctrl+C` | 强制退出 |

### 方式二：编程调用

**基本用法**
```python
from alice.core import AliceBot

# 创建机器人实例
alice = AliceBot()

# 获取回复
response = alice.respond("你好")
print(response)  # 输出：你好！很高兴和你聊天。
```

**多轮对话**
```python
from alice.core import AliceBot

alice = AliceBot()

conversation = [
    "你好",
    "我最近感觉很迷茫",
    "不知道未来的方向在哪里",
    "你有什么建议吗"
]

for msg in conversation:
    response = alice.respond(msg)
    print(f"你：{msg}")
    print(f"Alice: {response}\n")
```

**获取对话摘要**
```python
alice = AliceBot()

alice.respond("我朋友小明最近升职了")
alice.respond("我为他感到高兴")

# 获取对话状态
summary = alice.get_conversation_summary()
print(f"对话轮数：{summary['turns']}")
print(f"提及的人物：{summary['recent_entities']}")
print(f"脚本使用情况：{summary['script_usage']}")
```

**重置对话**
```python
alice = AliceBot()

# ... 一些对话后 ...

# 重置对话状态
alice.reset()
print("对话已重置")
```

### 方式三：Web 界面（可选）

**启动 Web 服务器**
```bash
# 安装 Flask（如果未安装）
pip install flask

# 启动服务器
python alice/server.py
```

**访问聊天界面**

打开浏览器访问：`http://localhost:5000`

**API 端点**

| 端点 | 方法 | 说明 |
|------|------|------|
| `/` | GET | Web 聊天界面 |
| `/api/chat` | POST | 聊天 API |
| `/api/reset` | POST | 重置对话 |
| `/api/status` | GET | 获取状态 |

**API 使用示例**
```bash
# 发送聊天请求
curl -X POST http://localhost:5000/api/chat \
  -H "Content-Type: application/json" \
  -d '{"message": "你好"}'

# 响应
{
  "response": "你好！很高兴和你聊天。",
  "timestamp": "2024-01-01T12:00:00"
}
```

## ⚙️ 自定义配置

### 修改对话脚本

脚本文件位于 `alice/scripts/curiosity_scripts.json`

**脚本结构**
```json
{
  "意图名称": {
    "patterns": ["匹配模式 1", "匹配模式 2"],
    "responses": ["响应 1", "响应 2", "响应 3"],
    "priority": 5
  }
}
```

**添加新意图**
```json
{
  "hobby_discussion": {
    "id": "hobby_discussion",
    "name": "爱好讨论",
    "patterns": [".*(喜欢 | 爱).*", ".*(兴趣 | 爱好).*"],
    "responses": [
      "这个爱好很有趣！你是怎么开始的？",
      "做这件事的时候你感觉怎么样？",
      "这个爱好对你来说意味着什么？"
    ],
    "priority": 4
  }
}
```

**修改现有响应**

1. 打开 `alice/scripts/curiosity_scripts.json`
2. 找到对应的意图类别
3. 修改 `responses` 数组中的内容
4. 保存文件，重新运行程序

**优先级说明**
- `6-7`: 高优先级（问候、紧急情况）
- `4-5`: 中优先级（叙事、情感、人物）
- `1-3`: 低优先级（通用回应）

### 调整代词转换

编辑 `alice/core.py` 中的 `ReflectionEngine` 类：

```python
class ReflectionEngine:
    def __init__(self):
        # 修改代词映射表
        self.pronoun_mapping = {
            '我': '你',
            '我的': '你的',
            # 添加自定义映射
            '我家': '你家',
            '我老婆': '你老婆',
        }
```

### 启用日志记录

```python
from alice.core import AliceBot

# 启用日志（会创建 logs/ 目录）
alice = AliceBot(enable_logging=True)

response = alice.respond("你好")
```

日志文件位置：
- 对话日志：`logs/dialogue_YYYY-MM-DD.log`
- 性能日志：`logs/performance_YYYY-MM-DD.log`
- 错误日志：`logs/error_YYYY-MM-DD.log`

## ❓ 常见问题

### Q1: 为什么响应有时候不准确？

**原因**: Alice 使用基于规则的匹配，如果输入不在预设模式中，可能无法准确匹配。

**解决方法**:
1. 尝试换一种说法
2. 添加更多响应变体到脚本文件
3. 检查脚本中的 pattern 是否覆盖你的输入

### Q2: 如何安装 jieba 分词？

```bash
pip install jieba
```

如果安装失败，可以尝试：
```bash
pip install jieba -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3: 响应时间慢怎么办？

**可能原因**:
- 首次加载需要初始化
- 系统资源不足
- 对话历史过长

**解决方法**:
1. 确保已安装 jieba（未安装时使用基础模式）
2. 定期调用 `alice.reset()` 清空对话历史
3. 关闭其他占用资源的程序

### Q4: 如何集成到我的项目？

```python
from alice.core import AliceBot

class MyApplication:
    def __init__(self):
        self.alice = AliceBot(script_file="path/to/custom_script.json")
    
    def handle_user_message(self, user_input):
        """处理用户消息"""
        try:
            response = self.alice.respond(user_input)
            return {'success': True, 'response': response}
        except Exception as e:
            return {'success': False, 'error': str(e)}
```

### Q5: 可以离线使用吗？

**可以**。Alice 完全本地运行，不需要联网（除非你启用了需要联网的可选功能）。

### Q6: 支持其他语言吗？

当前版本仅支持中文。如需支持其他语言，需要：
1. 修改脚本文件中的模式
2. 调整代词映射表
3. 可能需要修改分词逻辑

## 🔧 技术说明

### 系统架构

```
用户输入
    ↓
文本预处理（标准化、分词）
    ↓
语义分析（情感、意图、实体）
    ↓
脚本匹配（正则表达式）
    ↓
反射转换（代词转换）
    ↓
响应生成
    ↓
输出
```

### 性能指标

| 指标 | 目标 | 实际 |
|------|------|------|
| 响应时间 | ≤2 秒 | ~50-200ms |
| 内存占用 | <50MB | ~20MB |
| 启动时间 | <1 秒 | ~100ms |

### 依赖说明

**核心依赖**
- `jieba`: 中文分词工具（约 3MB）

**可选依赖**
- `flask`: Web 界面支持
- `pytest`: 测试框架

### 文件结构

```
eliza-py/
├── alice/
│   ├── core.py                    # 核心对话引擎
│   ├── server.py                  # Web 服务器
│   ├── scripts/
│   │   └── curiosity_scripts.json # 好奇心脚本
│   └── utils/
│       ├── context.py             # 上下文管理
│       ├── logger.py              # 日志记录
│       └── performance.py         # 性能监控
├── docs/                          # 项目文档
├── tests/                         # 测试文件
├── requirements.txt               # 依赖配置
└── README.md                      # 项目说明
```

### 数据隐私

- 所有对话数据本地存储
- 日志文件保存在 `logs/` 目录
- 不会上传任何数据到外部服务器
