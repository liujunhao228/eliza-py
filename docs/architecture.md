## 🔄 核心对话流程图

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           用户输入："我昨天和朋友去了一家新餐厅"                  │
└─────────────────────────────────────┬───────────────────────────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      1. 文本预处理               │
                    │  - 去除空白/特殊字符             │
                    │  - 输入验证                      │
                    └────────────────┬────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      2. NLP 分析                 │
                    │  ┌───────────────────────────┐  │
                    │  │ JiebaEngine (必选)        │  │
                    │  │ - 分词：我/昨天/和/朋友/...│  │
                    │  │ - 词性标注：我/r 昨天/t... │  │
                    │  └───────────────────────────┘  │
                    │  ┌───────────────────────────┐  │
                    │  │ LtpEngine (可选)          │  │
                    │  │ - 实体识别：朋友 (人物)    │  │
                    │  │ - 依存分析：主谓宾结构     │  │
                    │  └───────────────────────────┘  │
                    └────────────────┬────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      3. 意图匹配                 │
                    │  遍历 YAML 脚本 (按优先级)        │
                    │  ┌───────────────────────────┐  │
                    │  │ 脚本 1: greeting (85)     │  │✗│
                    │  │ 脚本 2: narrative (80)    │  │✓│
                    │  │ 脚本 3: question (75)     │  │  │
                    │  └───────────────────────────┘  │
                    │  匹配结果：narrative (叙事延续)  │
                    └────────────────┬────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      4. 上下文更新               │
                    │  - 记录用户提到的实体 (朋友、餐厅)│
                    │  - 更新对话轮次                  │
                    │  - 保存最近对话历史              │
                    └────────────────┬────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      5. 响应生成                 │
                    │  - 选择模板："你提到的这个朋友..." │
                    │  - 代词转换：我→你，你→我        │
                    │  - 实体填充：朋友→具体人物       │
                    └────────────────┬────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      6. 插件处理                 │
                    │  - CuriosityPlugin: 添加追问    │
                    │  - EmotionPlugin: 情绪响应      │
                    └────────────────┬────────────────┘
                                      ▼
                    ┌─────────────────────────────────┐
                    │      输出："你提到的这个朋友，   │
                    │            ta 是个怎样的人呀？"   │
                    └─────────────────────────────────┘
```

## 🔀 意图匹配决策树

```
用户输入
    │
    ├── 包含"你好/您好/嗨" ──────────────► greeting (问候)
    │                                      响应："你好！我是 Alice..."
    │
    ├── 包含"再见/拜拜/quit" ───────────► farewell (告别)
    │                                      响应："再见！很高兴..."
    │
    ├── 包含"为什么/怎么了/心情" ───────► emotion (情绪)
    │                                      响应："为什么会有这种想法？"
    │
    ├── 包含"朋友/同事/同学/他/她" ─────► character (人物关注)
    │                                      响应："ta 是个怎样的人？"
    │
    ├── 包含"后来/然后/之后/接着" ──────► narrative (叙事延续)
    │                                      响应："后来呢？发生了什么？"
    │
    ├── 包含"觉得/认为/想法/观点" ──────► reflection (自我反思)
    │                                      响应："这个想法对你有什么影响？"
    │
    └── 无匹配 ─────────────────────────► default (默认)
                                           响应："能多说说吗？"
```

## 🏭 NLP 工厂模式架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                      NLPFactory (单例)                           │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │                    引擎注册表                               │ │
│  │  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐     │ │
│  │  │ JiebaEngine  │  │  NerEngine   │  │  LtpEngine   │     │ │
│  │  │ (分词引擎)    │  │ (实体引擎)    │  │ (句法引擎)    │     │ │
│  │  │ 优先级：1     │  │ 优先级：2     │  │ 优先级：3     │     │ │
│  │  │ 状态：active  │  │ 状态：active  │  │ 状态：lazy    │     │ │
│  │  └──────────────┘  └──────────────┘  └──────────────┘     │ │
│  └────────────────────────────────────────────────────────────┘ │
│                                                                  │
│  ┌────────────────────────────────────────────────────────────┐ │
│  │                    统一接口                                 │ │
│  │  analyze(text) → NLPResult                                 │ │
│  │    ├─ tokens: List[Token]                                  │ │
│  │    ├─ entities: List[Entity]                               │ │
│  │    ├─ dependencies: List[Dependency]                       │ │
│  │    └─ triples: List[Triple]                                │ │
│  └────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────────┐
│                        调用示例                                  │
│                                                                  │
│  factory = NLPFactory.get_instance()                            │
│  result = factory.analyze("小明在北京大学读书")                   │
│                                                                  │
│  # 直接使用引擎                                                  │
│  jieba = factory.get_engine('jieba')                            │
│  tokens = jieba.segment("今天天气很好")                           │
│                                                                  │
│  # 降级策略                                                       │
│  try:                                                            │
│      result = factory.analyze(text)  # LTP                      │
│  except LTPError:                                                │
│      result = factory.analyze(text, engine='jieba')  # 降级      │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```
