# Alice 模块快速参考卡片

## 🚀 快速开始

### 基本使用
```python
from alice.alice_v2 import AliceBot

# 创建机器人实例
bot = AliceBot()

# 生成响应
response = bot.respond("你好")
print(response)

# 获取统计信息
stats = bot.get_stats()
```

### 启用高级功能
```python
# 启用插件系统
bot = AliceBot(enable_plugins=True)

# 启用 LTP 增强
bot = AliceBot(use_ltp=True)

# 自定义缓存大小
bot = AliceBot(cache_size=200)
```

## 📦 核心模块速查

### AliceBot (主类)
```python
AliceBot(
    script_file=None,      # 脚本文件路径
    rules_file=None,       # 规则文件路径
    enable_logging=True,   # 启用日志
    enable_plugins=True,   # 启用插件
    cache_size=100,        # 缓存大小
    use_ltp=False          # 使用 LTP
)
```

**常用方法：**
- `respond(text)` - 生成响应
- `get_stats()` - 获取统计
- `reset()` - 重置对话
- `cleanup()` - 清理资源

### SemanticAnalyzer (语义分析)
```python
from alice.processors import SemanticAnalyzer

analyzer = SemanticAnalyzer(use_ltp=False)
result = analyzer.analyze("我觉得很开心")

# 结果包含：
# - tokens: 分词结果
# - sentiment: 情感分数 [-1, 1]
# - intent: 意图类型
# - entities: 实体列表
```

### PluginManager (插件管理)
```python
from alice.plugins import PluginManager, BasePlugin

manager = PluginManager()

# 注册插件
manager.register_plugin("my_plugin", MyPluginClass)

# 初始化所有插件
manager.initialize_all()

# 处理输入
results = manager.process_input("用户输入", context)
```

### ContextManager (上下文管理)
```python
from alice.managers import ContextManager

ctx = ContextManager()

# 更新上下文
ctx.update(
    user_input="用户说了什么",
    bot_response="机器人回复",
    entities=[("person", "小明")],
    sentiment=0.5,
    intent="narrative"
)

# 获取最近对话
recent = ctx.get_recent_turns(3)
```

## 🔧 配置管理

### 基本配置
```python
from alice.managers import ConfigManager

config = ConfigManager()

# 设置配置
config.set("plugin.curiosity.priority", 50)
config.set("cache.max_size", 200)

# 获取配置
priority = config.get("plugin.curiosity.priority", 50)
```

### 环境变量
```bash
# 启用 LTP
export ALICE_USE_LTP=true

# 设置缓存大小
export ALICE_CACHE_SIZE=150

# 日志级别
export ALICE_LOG_LEVEL=INFO
```

## 📊 性能监控

### 获取统计信息
```python
stats = bot.get_stats()

# 关键指标
print(f"缓存命中率: {stats['cache']['hit_rate']}")
print(f"平均响应时间: {stats['monitor']['avg_response_time']}ms")
print(f"插件成功率: {stats['plugins']['success_rate']}")
```

### 性能基准
```
基础模式: <50ms 响应时间
LTP 模式: <200ms 响应时间
内存占用: 50-200MB (取决于配置)
```

## ⚡ 常见问题

### Q: 如何禁用某个插件？
```python
config = ConfigManager()
config.set("plugin.curiosity.enabled", False)
```

### Q: 如何自定义响应模板？
编辑 `alice/scripts/curiosity_scripts.yaml` 文件

### Q: 如何查看详细日志？
```python
import logging
logging.basicConfig(level=logging.DEBUG)
```

### Q: 如何处理 LTP 初始化失败？
系统会自动降级到轻量级模式，不影响基本功能。
